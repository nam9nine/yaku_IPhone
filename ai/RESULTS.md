검증일: 2026-10-25 KST. 실제 장비는 시스템에서 확인한 **Apple M5·24GB, macOS 26.5.2**다. M5 Pro로 측정한 결과가 아니다. Python 3.12.13·MLX-LM/MLX 0.32.2와 고정 lockfile을 사용했다.

**4B·9B 기본 모델과 학습 모델 모두 이번 공학 품질 기준에 미달했다.** 9B 기본 모델을 임시 체험 기본으로 선택했으며, 현재 LoRA의 제품 채택은 보류한다. 독립 검토도 이 선택을 지지했지만 9B가 4B보다 우수하다는 판정은 아니다. 로컬 선택 파일의 상태는 `experimental_not_quality_passed`이고 어댑터는 지정하지 않았다.

## 실제 이력을 사용한 다중턴과 CLI 격리

9B 기본·학습 모델 각각 6개 시나리오를 4턴씩 실행했다. 미리 정해둔 답을 이력에 넣지 않고 실제 생성 답변을 다음 입력에 사용했다. 두 실행 모두 24/24턴이 정상 종료했으며 오류·길이 제한·건너뛴 턴은 각각 0개다. 이는 실행 완료 수이며 24개 답변의 의미 정확도나 팬 말투 점수가 아니다.

조정 에이전트와 별도 독립 검토자가 실제 대화와 다음 턴 입력을 읽어 다음을 관찰했다. 기본 모델은 한 약속 정정 시나리오에서 바뀐 시간·장소를 유지했지만, 학습 모델은 3턴에서 예전 시간으로 돌아가 4턴에도 반복했다. 다른 시나리오에서 학습 모델은 사용자가 알려준 물건 소유자를 바꾸고 그 오류를 뒤에서도 유지했다. 기본 모델 역시 물건 위치·소유자와 확인하지 않은 택배 상태를 꾸며냈다. 이 관찰 때문에 실행 성공만으로 대화 품질을 승인하지 않았다. 해당 검토에서 4B의 실제 다중턴은 비교하지 않았다.

별도 CLI 감사는 9B 학습 모델로 프로세스를 실제 4회 실행했다. 새 프로세스에서 같은 세션 이력을 다시 읽었고, 다른 방문자와 다른 인물의 입력에는 원래 세션의 검사 표식이 들어가지 않았다. **입력 격리는 확인했지만 모름 대응은 실패했다.** 분리된 입력만 받은 모델이 알고 있다고 주장한 응답은 실제 다른 방문자 기록에 접근했다는 증거가 아니다. 이 감사는 로컬 방문자·인물 키의 분리를 확인한 것으로, 공개 서비스의 인증·접근 제어 검증을 대신하지 않는다.

## 생성 지연과 FIFO 대기

다음은 한 프로세스에 모델 한 개를 올리고 요청별 KV 캐시를 새로 만든 내부 측정이다. 모델 로딩은 요청 지연에서 제외했다. 첫 텍스트는 생성기 내부 관측 시점이며 CLI는 완성된 답변을 한 번에 출력한다. **네트워크·웹 서버·폴링·휴대폰 표시 지연은 포함하지 않았다.**

개발 요청 전체에서 각 조건 120개를 순차 실행했다. 아래 지연의 단위는 초이고 `p50 / p95`다. 완료는 추론 서비스 시간이며 출력 토큰은 실제 생성 길이다.

| 조건    | 로딩  | 첫 텍스트     | 완료          | 출력 토큰 p50 / p95 | 실행 오류 / 길이 제한 |
| ------- | ----- | ------------- | ------------- | ------------------- | --------------------- |
| 4B 기본 | 0.879 | 0.237 / 0.289 | 1.079 / 2.663 | 38 / 104.6          | 0 / 3                 |
| 4B 학습 | 0.905 | 0.251 / 0.297 | 0.688 / 1.448 | 19 / 50.2           | 0 / 0                 |
| 9B 기본 | 1.233 | 0.420 / 0.496 | 1.427 / 3.028 | 24.5 / 65           | 0 / 0                 |
| 9B 학습 | 1.614 | 0.452 / 0.548 | 1.389 / 2.951 | 20 / 57.1           | 0 / 0                 |

4B 기본의 길이 제한 3건은 정상적으로 완성한 답변으로 세지 않는다. 4B 학습의 첫 토큰 p95는 0.296초이고 첫 텍스트는 0.297초다. 나머지 조건에서는 두 측정이 소수점 셋째 자리까지 같다. 학습 모델의 출력이 짧아졌으므로 완료 시간 감소를 동일 길이의 추론 처리 속도 향상으로 해석하지 않는다.

9B의 추가 부하 진단은 고정 개발 입력에서 고른 사실 on 32개를 각 조건에 동일하게 사용했다. `burst 2`는 16묶음, `burst 4`는 8묶음의 동시 도착을 가정해 **직렬 FIFO**로 처리했다. 병렬 GPU 추론이나 실제 웹 동시 접속 시험이 아니다. 각 행은 32개 요청의 `p50 / p95`이며, 첫 텍스트와 완료 모두 도착 후 대기를 포함한다.

| ------- | ----- | ----- | ------------- | -------------- | ------------- |
| 9B 기본 | 1     | 0.935 | 0.000 / 0.000 | 0.475 / 0.488  | 1.406 / 3.676 |
| 9B 기본 | 2     | 0.951 | 0.500 / 3.696 | 0.955 / 4.139  | 2.842 / 5.178 |
| 9B 기본 | 4     | 0.964 | 2.687 / 6.892 | 3.162 / 7.340  | 4.994 / 8.258 |
| 9B 학습 | 1     | 0.977 | 0.000 / 0.000 | 0.483 / 0.498  | 1.293 / 2.560 |
| 9B 학습 | 2     | 0.973 | 0.390 / 2.262 | 0.855 / 2.744  | 2.104 / 3.745 |
| 9B 학습 | 4     | 0.955 | 1.901 / 4.665 | 2.392 / 5.121  | 3.542 / 6.890 |

6개 실행 모두 오류·길이 제한은 0건이다. 실제 입력 길이는 285–381토큰, 중앙값 331토큰이다. 기본 출력은 11–119토큰(중앙값 25, p95 83.85), 학습 출력은 8–86토큰(중앙값 21, p95 53.7)이며 각 burst에서 같다. 이 9B 진단에서는 첫 토큰과 첫 텍스트 측정이 같았다. p95는 type 7 선형 보간값이고 각 32건의 짧은 개발 입력에 한정한다. 4요청 burst도 독립 묶음은 8개뿐이므로 운영 환경의 꼬리 지연을 보장하지 않는다.

내부 측정은 임시 공학 목표인 단일 첫 텍스트 p95 3초·완료 p95 10초와 4요청 도착→완료 p95 30초 이내였다. 이는 사용자에게 승인받은 SLA나 실제 웹 응답성 통과 판정이 아니다.

## 채택 상태와 남은 검증

`selected-model.json`은 **9B 기본 모델·어댑터 없음**을 가리킨다. 선호·문맥 집계의 일부 개선과 실제 다중턴의 회귀를 함께 고려해 현재 LoRA의 제품 채택을 보류했다. 임시 기본 모델도 모름 대응과 사실성 오류가 있으므로 품질 합격 모델로 표시하지 않는다.

팬의 한국어 말투 검토, 봉인 최종 평가, 4B·9B를 동일 검토자가 직접 비교하는 평가는 남아 있다. 웹 인증·방문자 소유권·브라우저 연동·실제 사용자가 기다리는 시간은 Issue 61의 별도 범위다. 이 로컬 실험 결과로 공개 서비스 검증까지 완료했다고 보고하지 않는다.

## 증거 위치

- `sources/manifest.json`: 원문 URL·접근 결과·해시·제외 이유.
- `data/pilot-v1/manifest.json`, `provenance.jsonl`: 분할·원 예시·검수 해시.
- `runs/*/manifest.json`, `token-audit.jsonl`, `training.jsonl`: 실제 설정·명령·토큰·가중치·재로드 결과.
- `eval/dev-fixed/`: 동일 입력과 고정 근거, 평가용 정답은 별도 private key.
- `eval/*-base-dev.jsonl`, `*-trained-dev.jsonl`: 실제 답변·생성 길이·종료·시간, 모델/어댑터 파일 해시.
- `eval/neutral-round-a/`, `round-a-reviewed/`: 블라인드 직접 판정과 결과 해시.
- `eval/neutral-round-b/`, `round-b-reviewed/`: 9B의 블라인드 직접 판정 120개와 모델별 항목 판정 120개씩의 변환 기록.
- `eval/*-summary.json`: 품질 원분모와 지연 집계. `9b-*-burst-*-summary.json`은 추가 FIFO 진단.
- `eval/9b-*-conversations/`: 실제 다중턴·다음 입력·종료 상태. 판정용 rubric은 모델 입력에서 분리.
- `eval/cli-audit/`: 프로세스 재실행·방문자·인물 입력 격리 기록.
- `selected-model.json`: 임시 기본 모델과 제품 품질 미통과 상태.
