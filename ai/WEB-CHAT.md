# 공개 사이트에서 Mac 모델과 문자 주고받기

GitHub Pages의 메시지 앱이 HTTPS를 통해 Mac의 모델에 요청한다. 하루카·마지마만 자유 입력을 지원하며, 모델 응답을 받기 전에는 입력 중 표시를 보여준다. 생성 실패를 고정 대사로 바꾸지 않는다. 원작 대사나 검증된 인물 재현이 아닌 실험 모델의 창작 IF 답변이다.

## 실행

학습과 대량 평가가 끝난 뒤 실행한다. 같은 Mac에 모델을 여러 개 동시에 올리지 않는다. 먼저 [로컬 실험 안내](README.md)에 따라 private 자료와 실제 평가한 모델을 준비한다. 새 checkout만으로 자료나 모델이 생기지 않는다.

```sh
sh ai/bootstrap-web.sh
sh ai/share.sh
```

기본 데이터 경로는 `references/local/kiryu-ai`, 선택 설정은 그 아래 `selected-model.json`이다. 경로가 다르면 `KIRYU_AI_DATA`를 지정한다. 모델을 명시하면 선택 파일의 어댑터를 암묵적으로 사용하지 않는다.

```sh
KIRYU_AI_DATA="$PWD/references/local/kiryu-ai-2026-10-25" \
  sh ai/share.sh --model "$PWD/references/local/kiryu-ai-2026-10-25/models/9b"
```

서빙 환경은 `.tooling/character-ai-web/venv`에 별도로 설치한다. 실행 중인 학습 환경을 변경하지 않기 위한 분리이며, `requirements-serve.lock`은 학습 환경 lock을 제약으로 삼아 생성했다. 서버 패키지 Starlette·Uvicorn과 CPU 계약 검사 패키지 httpx2를 추가했다. 프런트엔드 의존성은 추가하지 않았다.

`cloudflared`가 PATH에 있어야 한다. [공식 설치 안내](https://developers.cloudflare.com/tunnel/downloads/)를 따른다. 실행기는 `127.0.0.1:8765`에 자신의 API를 띄우고 준비 상태를 확인한 뒤 임시 터널을 연다. 이미 사용 중인 포트를 발견하면 다른 서비스를 노출하지 않고 종료한다.

터미널에 출력되는 `invite.txt` 파일의 링크를 휴대폰에서 연다. 링크에는 개인 접속 키가 있으므로 공개 이슈·PR·소스에 붙이지 않는다. 잠금 암호는 기존과 같은 **1225**다. 메시지를 열면 **Mac 연결** 창에서 연결할 서버를 확인하고 **연결**을 누른다. 이후 하루카 또는 마지마의 대화에서 직접 문자를 입력한다. 수동 설정은 메시지 목록의 **편집 → Mac 연결**에서 한다.

연결할 때 서버가 새 방문자 토큰을 발급한다. 이 브라우저에 토큰을 저장하므로 새로고침 후에도 해당 방문자의 대화를 이어간다. 다른 브라우저에서 같은 초대 링크로 연결하면 별도의 방문자다. 연결 해제 후 다시 연결하면 새 대화를 시작한다. 로컬 저장이 불가능하면 현재 화면에서만 연결한다.

`Ctrl+C`로 실행기를 종료하면 자신이 띄운 API와 터널을 함께 종료한다. Mac 잠자기·종료 또는 터널 종료 시 공개 사이트는 그대로 열리지만 AI 답장은 받을 수 없다. 재실행하면 새 초대 링크를 사용한다. [Quick Tunnel](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)은 임시 개발용이며 주소와 가동 시간을 보장하지 않는다. 이 구현은 SSE 대신 작업 접수와 상태 조회를 사용한다.

## 요청과 기록

- Mac에 모델 한 개를 올리고 전용 스레드에서 요청을 순서대로 처리한다. 방문자마다 동시에 한 요청, 대기열 최대 8개다.
- 브라우저는 인물·입력·요청 UUID만 보낸다. 프로필·상황·기억·원작 근거·모델 경로는 서버에서 조립한다.
- 토큰으로 방문자를 정하고 인물·시나리오별 기록을 분리한다. 사용자가 임의의 방문자 ID나 대화 이력을 제출할 수 없다.
- 같은 요청 ID의 재전송은 새 답장을 중복 생성하지 않는다. 연결 오류는 같은 요청으로 재시도하고, 잘못된 입력이나 생성 실패는 **다시 작성**으로 원문을 돌려받는다.
- 메시지는 최대 1000자·4096바이트, 입력과 출력 토큰 합은 현재 2048, 출력은 최대 128토큰이다. 대화가 한도에 도달하면 자동 삭제하지 않고 안내한다. 새 연결로 새 대화를 시작할 수 있다.
- 공개 앱 번들에는 모델·어댑터·원문·초대키·방문자 토큰을 넣지 않는다. 대화는 Mac의 private 데이터 디렉터리에 평문으로 저장되므로 이 Mac에 접근할 수 있는 소유자는 읽을 수 있다.

`web-access.json`은 초대키를, `web-sessions/auth.json`은 토큰 해시를, `web-sessions/`는 작업 상태와 대화를 보관한다. `web-share/current.json`은 현재 연결 주소·프로세스 ID·초대 파일 위치를 기록한다. 모두 ignored 로컬 자료다. 초대키가 있는 사람은 접속할 수 있으며, 계정 로그인·상용 운영 SLA·다중 Mac 분산 서빙은 이번 범위에 없다.

## 검증 범위

서버 CPU 테스트는 모델 대역으로 인증·소유권·재시도·상태 복구·오류를 검사한다. UI 계약 테스트의 고정 응답도 실제 추론 품질 증거가 아니다. 실제 모델 응답과 공개 Pages 연결 확인은 별도로 기록한다. 데스크톱 Chromium·WebKit 검사는 실제 iPhone Safari 검증을 대신하지 않는다.
