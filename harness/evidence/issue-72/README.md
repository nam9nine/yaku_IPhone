# Issue #72 실제 검색·기억 검증

독립 검토자가 원문·범위·질문을 먼저 고정한 40문항을 CPU multilingual-e5-small + BM25로 실행했다. 같은 저장 자료의 별도 개발 질문은 독립 평가라고 부르지 않는다.

- 정답 후보 회수: 30/32 (93.75%). 답할 수 없는 문항의 빈 검색: 5/8.
- 정답 후보 정밀도: 31/61 (50.82%). 문맥상 관련 후보: 36/65 (55.38%).
- 허용 범위를 벗어난 후보: 0. 최종 입력 예산 적용 전 검색 결과이며 실제 답변 정확도가 아니다.
- 출처 14개와 발췌 해시·범위 검토. 원본 1,201개 세계관 청크는 수정하지 않았다.
- 화자·현재 질문·후속 정정·예산·입력 재구성 회귀 검사 23개.

실제 다중턴 진단에서 최근 잡담이 옛 장보기 약속 검색을 밀어내는 실패가 있었다. 현재 문자로 첫 후보를 확보하고 최근 문맥으로 두 번째 후보를 보완하도록 수정했다. 이전 실패 4건의 고정 원문 이력을 사용한 실제 Gemma 재검사에서 네 답장 모두 우동면 정정을 반영했다. 이 재검사는 알려진 실패에 대한 수정 확인이며 독립 품질 점수가 아니다. 최초 실패 출력은 삭제하지 않았다.

AI가 먼저 제안한 약속의 정정을 놓치는 독립 리뷰 지적도 양쪽 화자 주제 연결과 세 회귀 검사로 수정했다. 원문은 후보 사실로 자동 변환하지 않는다.

전체 최종 다중턴·성능·공개 UI 검증은 #74에서 수행한다. 말투·판단·모르는 정보에 대한 답변은 여전히 별도 검토 대상이며 팬 검토는 미완료다.
