# Issue #73 검토 화면 캡처

합성 DB만 사용한 macOS 데스크톱 1440×1000 캡처다. 실제 방문자의 대화나 팬 평가 자료가 아니다. 관리자 전용 3열 화면이며 iPhone UI 일치도를 평가하지 않는다.

- `admin-review.png`: 정정 사례 원문과 여섯 축 검토, 하단 고정 저장 버튼.
- `admin-failure.png`: 잘린 출력과 스크립트 형태 텍스트를 실행 없이 표시.
- `admin-stats.png`: 버전별 표본 수와 평가된 축의 분모.
- `admin-webkit.png`: WebKit의 원문·평가 조작, 네이티브 select 차이.

작성자와 독립 검토자가 네 이미지를 직접 확인했다. Chromium·WebKit에서 평가 저장·필터·현황·선택 JSONL 내보내기를 합성 자료로 조작했다. 자동 기준 이미지는 변경하지 않았다.
