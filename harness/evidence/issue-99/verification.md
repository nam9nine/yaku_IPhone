# Issue 99 검증

2026-10-27, macOS arm64, Node 24.22.0, Playwright 1.64.1. 사용자 요청으로 CI와 전체 시각 baseline 회귀는 실행하지 않았다. 기준 이미지를 덮어쓰지 않았다.

- TypeScript 및 변경 파일 ESLint 통과.
- Vitest: replySound, pushWorker, messenger 55개 통과.
- Chromium/WebKit 관련 34개 1차 통과. 독립 검토에서 취소 경로 보완 후 키보드·전경 Push·무음/초기화/교차 창 초기화·긴 대화·알림 진입 22개 재검사 통과.
- build 및 harness:check 통과. 실제 API·OS Push 제공자는 브라우저 테스트에서 모의 처리했다. 모델 추론 품질 작업이 아니다.

주 에이전트가 dark/light 일반 대화 및 키보드 축소 캡처를 직접 열었다. 사용자가 제공한 실제 iPhone 메시지 화면과 비교하여 전체 헤더 경계 제거, 프로필 60px·이름 pill·뒤로 badge·알림 원형 버튼, 흐림 레이어, 파란 말풍선, 상태 아이콘을 확인했다. 영상통화 아이콘은 사용자 요청대로 알림으로 대체했다. 키보드 자체는 모사하지 않고 visualViewport 높이 축소로 입력창 끝이 viewport 끝에 닿는지 검사했다. 실제 iPhone 키보드 및 설치 앱에서 들리는 음향은 미검증이다.

소리 취소 리뷰 지적: await 중 무음/초기화/해제 상태가 바뀌면 오래된 closure로 재생할 수 있었다. 현재 설정을 다시 읽고 pending AbortController 집합을 같은 창·다른 창 초기화/무음/해제에서 취소하도록 수정했다. 독점 playback 세션 고정은 제거하고 선택적 transient 세션만 사용한다.

키보드가 열린 동안에는 웹 하단 홈 제스처 띠를 숨겨 입력창을 밀착한다. 키보드가 닫히면 띠가 복구된다. 설치 앱의 실제 상태바는 기존 중복 숨김 규칙을 유지한다. 가상 배터리 값은 80이며 실제 기기 배터리를 읽지 않는다.
