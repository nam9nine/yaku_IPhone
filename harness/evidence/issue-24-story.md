# 키류의 폰 — Issue 24

연락처 다섯 명과 메시지, 메모, 사진을 공통 앱 셸에 연결했다. 세로 본문 스크롤·한 단계 뒤로·최근 앱·테마를 공유한다. 실제 통신은 없으며 메시지·초안·메모·체크리스트·즐겨찾기는 이 브라우저 저장소에 남는다.

## 조사와 직접 비교

`references/story-sources.json`과 `docs/kiryu-story.md`에 SEGA 인물·나팔꽃 출처 및 Apple iOS 27 원문/화면 출처를 기록했다. 원문과 Apple 화면은 `references/local/story/`, 배포에 사용하는 SEGA 이미지 10장은 `public/story/`에 있다. 공개된 이미지의 저작권을 오픈 라이선스로 주장하지 않는다. 대화·개인 메모는 팬 창작이고 특정 정사 연도를 고정하지 않는다.

Apple 공식 연락처 카드, 메시지 목록·대화, 메모, 사진 보관함·상세 이미지를 직접 열었다. 큰 원형 프로필과 연락 동작, 하단 검색, 파랑/회색 말풍선, 메모 체크리스트, 사진 3열 격자와 필름스트립을 비교했다. 사에지마 전신 이미지의 얼굴 크롭, 읽던 대화 스크롤 복귀, 사진의 겹침 헤더·하단 세로 아이콘 탭을 보완했다. 통화·메일·첨부·공유처럼 이번 범위에서 구현하지 않은 버튼은 두지 않았다.

## 검증

macOS arm64 / Node24.22.0 / Playwright1.64.1 Chromium·WebKit. 360×800, 390×844, 430×932의 8장면×2엔진 신규48장과 연락처 아이콘·검색 목록 변경8장을 직접 검토했다. 기존54장은 유지한다. macOS와 Linux 기준은 구현에 참여하지 않은 `agent:/root/story_research`가 각각 직접 검토해 등록을 승인했다. Linux 후보는 PR Actions 실행 `40001268205`의 실제 캡처이며 각 엔진의 기존 기준 27장씩(총54장)은 바이트가 동일하다. 최종 SHA·실행 결과는 PR의 harness-evidence에 연결한다.

전체 동작258개 통과에는 5인 모두 메시지 전송/새로고침 보존, 메모 수정·체크·생성·삭제, 사진 즐겨찾기, 앱 복귀·가장자리 뒤로, 가상 연결 해제/복구, 저장 거부 및 360×430 화면 입력을 포함한다. 독립 실행에서는 긴 대화의 scrollTop50이 홈/제어센터 복귀 뒤에도 유지됨을 확인했다. 메모 삭제 확인 중 앱 전환과 재진입도 양 엔진에서 확인했다. 프로필 사진·말풍선 터치 후 BODY 포커스에서 Escape가 누락되던 문제를 활성 앱의 window 키보드 처리로 보완하고 양 엔진 회귀 검사를 추가했다. 초기 테스트의 searchbox 역할 및 모음→즐겨찾기 탐색 오류는 실제 화면 구조에 맞춰 수정했다.

실제 iPhone Safari 및 실제 소프트 키보드는 미검증이다. 낮아진 viewport로 입력창 노출을 확인한 결과를 실기기 키보드 검증으로 표현하지 않는다. 모든 iOS 기능·배치의 완전 동일 구현은 아니며 사용자 지정 스토리와 기본 앱 기능 범위의 비교다. 최종 Linux 검사와 Pages 공개 확인은 PR/Issue에 기록한다.
