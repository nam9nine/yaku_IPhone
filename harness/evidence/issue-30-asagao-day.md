## 직접 화면 비교와 기준 변경

Apple의 기존 iOS 27 메시지·메모·잠금·홈 자료를 주 기준으로, Apple iOS 18의 위젯 배치를 보조 자료로 비교했다. 기존 프로젝트 스타일을 유지하면서 생활 콘텐츠·사진 위젯·세 개 잠금 위젯·PC 프레임을 적용했다. Apple UI 전체와 완전히 동일하다고 판정하지 않는다.

기준 변경 이유는 가상 시각 16:40, 실제 생활 이미지, 홈의 8개 작동 앱, 메시지·메모 초기 내용, 추가 앱, 알림 카드와 PC 프레임의 의도된 변경이다. macOS 후보 94장과 신규 장면 8장, 수정된 알림·설정 8장을 이전 이미지와 독립 비교했다. 최종 기준 중 바이트가 다른 WebKit 5장도 다시 직접 확인했다. 앱 수 감소로 더 이상 존재하지 않는 큰 화면의 두 번째 홈 기준은 제거하고 작은 높이의 두 번째 페이지를 별도로 검사한다. 비교 허용 오차나 마스크를 넓히지 않았다.

추적된 대표 캡처는 [issue-30/](issue-30/)의 22장이다. 잠금·홈·대화·메모·사진·미리 알림·캘린더·전화·알림 센터·PC·장보기 완료 상태를 두 엔진으로 보관한다. 실제 사진의 얼굴은 시계와 위젯 아래에 배치하고 홈 배경은 읽기 쉬운 정도로 흐리게 했다.

Linux CI `40026351521`의 130개 시각 장면 중 28개는 기존 기준에 일치했고 102개는 의도된 변경 또는 신규 기준 부재로 실패했다. 해당 실행 artifact의 실제 이미지 102장을 Linux 이전 기준과 18개 비교 시트로 직접 확인하고 `/root/asagao_review`의 독립 승인을 받은 뒤 등록했다. 새 앱의 18개 실패 캡처는 명시적인 assert 직전 캡처와 바이트가 일치하며 신규 8개 day 장면은 고정 조건의 실패 시점 캡처다. Calendar 포커스 수정 이후 macOS 일반 시각 검사 130개도 다시 통과했다. Linux 최종 일반 검사의 통과 여부는 다음 CI 결과로 별도 확인한다.

## 이미지와 남은 제한

- 식사 장면·인물은 실제 SEGA 공식 자료다. 도시락·텃밭·바다는 실제 촬영된 CC 자료이며 출처·저작자·라이선스를 사진 상세와 [자산 문서](../../docs/asagao-assets.md)에 기록했다. 가족 그림은 프로젝트 창작이며 공식 게임 이미지가 아니다.
- 원본은 참고 자료로 보관하고 공개 앱에는 로컬 자산만 포함한다. 실제 사진 세 장의 서버 제공 1280px 축소본 합계는 1,238,778바이트다.
- SEGA 이미지의 개별 웹앱 재배포 허가가 확인됐다고 주장하지 않는다. 대사·메모·일정·사진 설명과 가상 시각·날씨는 창작이다.
- 실제 iPhone Safari, 실제 iOS 키보드와 기기 성능은 미검증이다. 데스크톱 WebKit 결과로 대신 주장하지 않는다.
- 검색 결과의 캘린더 아이콘에 날짜가 빠지는 비차단 표시 문제는 [Issue #32](https://github.com/nam9nine/yaku_IPhone/issues/32)에 기록했다. 홈 아이콘 날짜와 앱 진입은 정상이다.
- 최종 CI와 Pages 배포 결과는 실제 실행 후 PR·Issue 기록에 추가한다. 이 문서의 로컬 통과를 배포 완료로 간주하지 않는다.
