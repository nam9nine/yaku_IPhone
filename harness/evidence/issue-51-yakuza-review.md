# Issue 51: 2차 검토 자료 실행 기록

대상은 [Issue 51](https://github.com/nam9nine/yaku_IPhone/issues/51)이다. 원문·정규화 run을 유지하면서 검토 자료를 파생했다. UI 변경이나 모델 학습은 수행하지 않는다.

## 입력과 실제 실행

입력은 Issue 47에서 다시 검증한 run `19ecc5cef2b47ca30326eeb2`다. Node 24.22.0, macOS 26.5.2 arm64에서 다음 명령을 두 번 실행했다.

```sh
node scripts/review-yakuza.mjs --data-dir /Users/namgyu/yaku_IPhone/references/local/yakuza-corpus --input-run 19ecc5cef2b47ca30326eeb2
```

출력은 `reviews/5566cae09b9221bf7e4eea04/`다. 두 번째 실행은 전수 재처리 후 `reproduced: true`였으며, root가 전체 출력 파일의 실제 바이트 수와 SHA-256을 다시 계산해 manifest와 일치함을 확인했다. 입력 정규화 pointer는 유지하고 `latest-review.json`만 별도로 게시했다.

## 행 수와 분류

입력 285,971행은 후보 47,588행과 보류 238,383행으로 나뉘며 삭제한 행은 없다. 보류는 폐기가 아니라 별도로 검토할 자료다.

| 파생 분류              |   행 수 |
| ---------------------- | ------: |
| 일반 대사 문맥 검토    |  47,588 |
| 게임 진행 문맥 검토    |   4,416 |
| 메일 제목·내용 검토    |     256 |
| 메일 이름·라벨 검토    |      30 |
| 이름 검토              |  33,229 |
| `ko` 열 없음           | 117,322 |
| 언어·태그 등 품질 검토 |  25,353 |
| UI 출처 검토           |  31,145 |
| 기타 출처 검토         |  26,632 |

게임·분류 안에서 인물 언급·분류 사유·언어 경고로 나눈 268개 층에서 SHA-256 순위로 고른 고유 표본은 711개다. 전체 인물 명단이나 전체 정확도 추정치가 아니다. 인물 언급이 없는 행도 보존하며, 이름을 발화자로 확정하지 않았다.

비어 있지 않은 전체 `ko` 열의 정제 문자열 완전 일치를 묶은 그룹은 같은 source 문맥 후보 3,052개, 서로 다른 source 문맥 후보 18,386개다. 언어가 실제 한국어인지, 같은 의미인지, 실제 대화 문맥인지는 확정하지 않는다. 중복으로 삭제한 행은 0개다.

## 검증과 제한

최종 `npm run check`는 타입·lint·포맷·301개 테스트·빌드·하네스를 통과했다. 별도 관련 테스트 67개도 통과했다. `src/`·`public/`·앱 의존성·화면 기준 이미지는 변경하지 않았으며 앱 산출물 해시는 기존과 동일하다. UI 변경이 아니므로 로컬 브라우저·이미지 검토를 새로 실행하지 않았고, 저장소의 필수 CI·배포 검사는 유지했다.

합성 검사는 source-field 분류, 단어만으로 대사 제거하지 않기, 짧은 문장과 다른 장면 반복 보존, 결정론적 표본, checksum·행 수·참조 검증, 기존 출력 보존, 실패 정리와 pointer 게시 실패 rollback을 포함한다. 실제 검사 결과와 최종 독립 리뷰는 PR의 현재 SHA에 연결한다.

root와 독립 검토자가 실제 표본을 읽었다. 일반 대사 후보에 줄거리 서술문이 있고 게임 진행 문맥에도 실제 짧은 발화가 있으며, 메일에는 제목과 내용이 섞인다. 따라서 명칭을 메일 제목·내용 검토로 구체화하고 이 한계를 문서화했다. 문장을 삭제하거나 화자를 추정하는 규칙은 추가하지 않았다. 초기 run `2fd0a8d07c12472b66a4bcaf`에 대한 독립 읽기 감사는 285,971행의 source·한국어 raw/clean·일본어·영어·미검증 라벨을 원본 정규화와 대조했고, 반복 그룹 전체와 당시 651개 표본의 SHA 순위도 다시 계산해 일치함을 확인했다.

초기 표본에는 혼합 숫자 필드 `21` 경고 150행 중 한 행도 들어오지 않았다. 이에 분류 사유·언어 경고를 별도 표본 층으로 추가했다. 최종 run은 이 경고를 대화·게임 진행·품질 검토에서 각각 3행씩, 총 9행 포함한다. 후보·보류·반복 그룹의 3개 파일은 초기 run과 SHA-256 및 바이트가 동일하다. 표본 보강은 후보 선별이나 원문을 변경하지 않았다. 최종 표본의 독립 감사와 현재 commit의 코드 검토 결과는 PR에 기록한다.

전수 재처리 집계와 파일 해시는 `references/yakuza-review-report.json`에 기록했다. 모든 텍스트는 ignored 로컬 출력에만 있으며 공개 저장소에는 합성 fixture와 집계만 넣는다. 모든 행의 화자·청자·시점·대화 순서는 미확정이며 `trainingEligible`은 false다. 이 결과는 SFT 대화쌍이나 학습/평가 분할을 생성한 결과가 아니다.
