# Issue 18 시스템 제스처와 고정 화면

2026-10-23, macOS 26.5.2 arm64 / Node 24.22.0 / Playwright 1.64.1. 최종 검증 SHA는 PR 본문에 연결한다. 사용자 결정은 앱 본문까지 세로 스크롤 금지, 하단에서 올리고 바로 놓기는 홈, 올린 뒤 멈추면 최근 앱이다.

## 구현과 조사

`docs/gestures.md`에 Apple 공식 기본 제스처·앱 전환·제어 센터·알림 센터·interactive pop와 MDN touch-action 자료, 시작 영역과 취소 규칙을 기록했다. 원문 HTML과 두 공식 이미지는 로컬 `references/upstream/apple/`에 저장하고 출처·날짜·SHA-256을 manifest에 관리한다. 외부 코드는 앱에 채택하지 않았다.

제어 센터는 설정과 가상 연결·밝기·테마를 공유한다. 최근 앱은 MRU 탐색·선택·위로 닫기를 제공하고 닫은 앱의 세션만 초기화한다. 홈 검색은 지원 앱 두 개만, 알림 센터는 빈 목록만 제공한다. 앱 가장자리 뒤로는 현재 UI 층 또는 방문 스택을 한 단계 이동한다. 긴 본문과 작은 홈은 가로 페이지로 접근한다.

실제 iOS 본문은 세로 스크롤을 지원하지만 이 프로젝트는 사용자 선택에 따라 가로 페이지를 사용한다. 웹은 실제 OS 화면·시스템 제스처를 대체하지 않는다. 가상 Wi-Fi·Bluetooth 토글은 실제 제어 센터의 일시 연결 해제와 다르다.

## 관찰한 수정

- 작은 화면에서 기존 스크롤 기반 테스트의 설정 실행이 숨은 홈 페이지에서 대기했다. 실제 홈 페이지 버튼으로 아이콘을 찾도록 검사 절차를 갱신했다.
- 드래그 중 두 번째 포인터·취소·blur·resize·캡처 이동과 텍스트 선택을 검사했다. child implicit capture의 이동을 전체 입력 취소로 오인하지 않도록 수정했다.
- 시스템 화면을 여는 중 기존 잠금/홈 드래그가 완료되던 문제와 앱 닫기 animation의 오래된 완료 callback을 수정하고 양 엔진 회귀 검사를 추가했다.
- 독립 점검에서 발견한 홈 페이지 수 축소 후 첫 방향키 무응답과 WebKit Tab 누락을 수정했다.
- 실제 최근 앱 캡처에서 Safari 본문이 숨겨지는 문제를 표시 상태/입력 활성 분리로 수정했다. 패널 전역 SVG 규칙이 미리보기 그림을 축소하던 문제도 아이콘 전용 class로 제한했다.
- WebKit 배경 흐림과 작은 높이의 intrinsic grid 폭을 보완했다. 실제 rem 확대에 따라 제어·알림 내용을 가로로 분할하고 짧은 안내 페이지를 추가했다.
- WebKit 360×320/200%의 설정 legend 1.5px 넘침은 불필요한 float 재정의를 제거했다. 독립 검토자의 CSS 실험에서 양 엔진 12개 화면의 텍스트와 label 범위가 정상으로 돌아왔다.

## 실행 결과와 시각 기준

타입·lint·포맷·단위 181개·production build·하네스가 통과했다. Chromium/WebKit 전체 동작 214개가 통과했다. Chromium은 CDP 실제 touch 입력으로 상단 당김, 하단 멈춤, 본문 가로 이동, 링크 시작 드래그와 가장자리 탐색을 검사했다. WebKit은 pointer 경로다. 360×800, 390×844, 430×932와 360×420/200% 확대, viewport 변경·취소·키보드·reduced motion을 포함한다.

legend 보완 후 관련 앱 동작 62개를 다시 실행해 통과했다. macOS에서 검토한 기준을 등록한 뒤 일반 `npm run test:visual` 실행의 56개가 모두 통과했다.

시각 검사는 09:41 / 2026-10-23 / ko-KR / Asia-Seoul에서 제품 컴포넌트를 캡처한다. 새 시스템 패널 16장과 기존 앱·홈 34장의 의도된 배치 변경을 직접 열어 검토했다. 대표 화면 14장은 `images/issue-18/`에 보관했다. 잠금 기본 6장은 유지한다. 이전 기준은 `af581c4`이며 문서에는 기존/후보 이미지 비교와 실제 검사 결과만 남긴다. 일반 실행은 기준을 덮어쓰지 않는다.

Apple 공식 제어 센터와 비교한 반투명 재질·둥근 조작 그룹, 앱 전환기와 비교한 카드·아이콘·홈 배경 흐림을 기준으로 직접 확인했다. 제어 수와 앱 수를 줄인 기본 화면, 가로 페이지 버튼, 닫기·홈 보조 버튼은 이 프로젝트의 차이다. 가짜 기기 프레임·상태바·Island·홈 인디케이터는 없다.

실제 iPhone Safari·소프트 키보드는 미검증이다. CI와 공개 배포 결과는 실행 후 PR/Issue에 기록한다.
