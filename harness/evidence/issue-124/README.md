# 기존 화면 기준과 비동기 검사 정리

볼링 구현 전 `53e7d8b`의 화면을 과거 기준과 비교했다. 제품 소스나 허용 오차를 변경하지 않았다.

| 차이                                                                 | 확인한 이전 변경 |
| -------------------------------------------------------------------- | ---------------- |
| Safari·Taxi 사용 안내 제거, 최근 앱의 같은 Safari 화면               | `1308416`        |
| 하루카 하단 안내와 잠금 암호의 크리스마스 힌트 제거                  | `8632826`        |
| 과거 대화·메시지 미리보기 확장, 이치반 연락처, 전화의 중복 시각 제거 | `8234019`        |

잠금 화면 두 장면은 전화 거절 뒤 AI 후속 문자와 이야기 배너가 교체되는 중간 상태를 캡처했다. 이제 실제 후속 문자가 도착한 뒤 화면의 닫기 버튼을 눌러 배너를 닫고 잠금 위젯을 비교한다. CSS 마스킹은 사용하지 않았다. Chromium·WebKit 4장의 반복 캡처는 바이트 단위로 같았다.

마지마의 강제 선택지가 이미 없어진 동작에 맞춰 기존 두 브라우저 테스트를 자유 입력 검사로 변경했다. 하루카 선택 검사는 유지하며 해당 시나리오와 무관한 통화 후속 대기를 fixture에서 제외했다. 두 인물 도착 단위 검사는 무작위 지연 상한과 타이핑 시간을 모두 기다린 뒤 기존 검증을 수행한다.

## 실제 검토

- macOS / Node 24.22.0 / Playwright 1.64.1.
- `npm run check`: 505개 단위 테스트와 타입·lint·포맷·빌드·harness 통과.
- `npm run test:visual`: 224개 통과. 기준 66장 갱신과 누락된 이치반 4장 등록 후 실행했다.
- 독립 검토자 `/root/baseline_review`: Chromium 기존/현재 17쌍, WebKit 8쌍, 이치반 신규 4장과 안정화한 잠금 화면 4장을 직접 확인했다. 나머지는 동일 변경의 크기별 회귀 검사 범위다.
- 조정 에이전트는 Safari, 메시지 목록, 암호 화면, 최근 앱 비교와 안정화한 잠금 화면을 직접 확인했다.

이 증거는 승인된 기존 변경과 기준의 일관성을 확인한다. Apple 원본과의 완전 일치, 실제 iPhone, 새 볼링 사건의 내용 품질 검증을 뜻하지 않는다. Linux 기준과 최종 전체 브라우저 결과는 해당 실행·검토 후 별도로 기록한다.

## Linux 첫 비교와 기존 브라우저 보완

CI 실행 `41093287048`은 이전 상태에서 브라우저 602개 통과·46개 실패 후 시각 검사 중 제한 시간에 도달했다. 이를 통과로 기록하지 않는다. Linux 실패 비교 38쌍 중 비동기 배너 경합 2쌍은 제외하고 승인된 기존 변경 36쌍과 이치반 신규 2장을 독립 검토 후 반영했다. 성공 시에도 저장되는 `actual` 파일은 실패로 분류하지 않았다. 아직 캡처되지 않은 WebKit 장면과 안정화한 잠금 화면은 다음 CI에서 확인한다.

기존 브라우저 검사 9개 파일은 현재 제품을 기준으로 수정했다. 짧아진 Safari 문서는 낮은 실제 viewport에서 페이지 이동을 확인하며, 메뉴도 화면의 페이지 버튼으로 조작한다. 연락처마다 과거 기록·자유 입력·선택 답장을 구분하고 읽음·새로고침·초안·중복 방지 검증을 유지했다. 제품 코드는 변경하지 않았다.

- 9파일 첫 통합: 159개 통과·5개 실패.
- 실패한 Safari·터치 조건을 수정한 최종 재검사: 28개 통과. 이전 5개 실패를 모두 포함한다.
- `/root/baseline_review`가 9파일 diff를 독립 검토했다. 검증 삭제·force 클릭·상태 강제 변경으로 실패를 숨기지 않았음을 확인했다.
- OCR의 JSON 조각 수신 성공 검사는 프로세스 시작 지연을 성능 요구로 오인하지 않도록 제한을 1초에서 5초로 변경했다. 별도 0.15초 실패 경계 검사는 유지했다. OCR 22개 검사와 독립 검토자의 관련 2개 검사가 통과했다.
