# 사건 상태와 작업 취소 검증

구현 대상은 schema 4, 활성 사용시간·소유권을 가진 사건 상태, 인증 API, assistant-only 선제 발신, FIFO 취소와 구버전 호환이다. 볼링 답장의 내용 품질과 공개 화면 전달은 후속 #122/#123의 완료 조건이다. 기능 플래그 기본값은 OFF다.

## 검증한 내용

- 독립 검토자가 최종 DB/API 변경과 완료 조건을 검토하고 사건 검사 21개를 실행해 통과했다. 별도 DB·push·사건 관련 81개 검사도 통과했다.
- 미활성 탭이 활성 탭을 막던 소유권 문제, 오래된 결과 저장, 통화 결과 문맥 보존을 수정 후 재검토했다.
- 대기 중 선제 작업은 큐에서 제거하고, 생성 중이면 정상 중단 처리와 감사 출력으로 분리한다. 정상 저장 전에 사건 버전과 최신 입력을 확인한다.
- 2026-10-31 KST, 운영 DB를 SQLite Backup API로 비공개 복사한 뒤 복사본만 schema 3→4로 이관했다. 원래 10개 테이블의 모든 기존 열을 정렬·해시 비교했다. 메시지 445개, 요청 229개를 포함해 값과 건수가 모두 같았다. 이관 재실행 후에도 같았고 foreign_key_check 0건, integrity_check ok였다. 운영 DB는 수정하지 않았다.
- 비공개 상세 기록: `references/local/gemma-chat/bowling-migration/20261030T181857Z/report.json`. 원문·세션 토큰·백업 DB는 Git에 포함하지 않는다.

위 기록은 실제 실행 범위다. 최종 PR head의 품질 검사·필수 CI·독립 리뷰는 PR 증거로 연결한다. 실기기, 실제 Gemma 내용 평가, 배포 후 원래 주소의 전달 확인을 완료했다고 표시하지 않는다.

## 전체 검사 실행 예산

선행 PR #125의 최신 CI `41105783134`는 브라우저 648개(19.0분)와 시각 224개(4.2분)를 모두 통과했지만 browser job은 설치를 포함해 24분 56초로 기존 25분 제한에 근접했다. 새 사건 검사 추가와 Pages의 품질 검사 시간을 수용하도록 browser 및 Pages build job 실행 예산만 35분으로 조정한다. 개별 테스트 제한, 시각 허용 오차, 필수 검사와 실패 판정은 변경하지 않는다.
