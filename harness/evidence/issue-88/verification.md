# Issue 88 관계·호칭과 실제 검색 검증

## 채택한 변경

키류 → 마지마의 `마지마 형님 / 형님`과 마지마 → 키류의 `키류쨩` 방향을 분리했다. 익숙한 연락·상호 인정과 협력을 카드에 반영하고, 일상 IF 예시 두 개를 원작 대사·실제 기억과 구분했다. 기존 방문자의 대화 원문은 수정하지 않았다.

한국어 게임 캡처는 명패와 대사를 직접 열어 확인했다. 번역판·게임 빌드는 미확정이며 학습 자료로 승격하지 않았다. PlayStation 편집 해설과 SEGA 공식 한국어 자료에서 관계·과거 사건을 별도로 채택했다. 원문 범위와 해시는 `ai/chat/registry.json`, 해석 범위와 출처는 `ai/CHAT_RELATIONSHIPS.md`에 있다.

관계 2개는 고정 입력, 과거 사건 2개는 동적 검색이다. 장면 검색에는 요약뿐 아니라 화자·상대·원문 대사를 사용한다. 검색 쿼리에서 호칭과 상투적 어미를 줄이되 실제 user 메시지·대화 이력·기억 검색은 바꾸지 않았다. 실행 자료는 22개 사실과 4개 장면이며, 1,201개 원문 청크 전체를 승인한 것이 아니다.

## 실행과 의미 평가

- macOS arm64, Node 24.22.0, Python 3.12.13. Gemma 4 26B-A4B IT Q4_K_M, 기존 llama-server 프로세스 하나, thinking ON, 문맥 6144·출력 상한 3072·생성 seed 42. 서비스와 같은 모델을 공유했으므로 무대기 성능 실험이나 p95 목표 달성으로 표현하지 않는다.
- 새 관계 단위 검사 5개 통과. 전체 AI 314개 검사에서 선택적 MLX 3개 제외 통과. 첫 병렬 실행은 변경하지 않은 OCR 조각 스트림 fixture의 1초 기한으로 1개 실패했고, 같은 전체 검사를 다시 실행해 통과했다. 제품 로직 수정으로 그 간헐 실패를 해결했다고 표시하지 않는다.
- `npm run check` 통과: 타입·lint·포맷·377개 단위·빌드·harness. Python 변경 파일 Ruff check/format 통과. UI 변경이 없어 브라우저·시각 회귀는 이 Issue의 필수 범위가 아니다.
- 독립 에이전트가 별도 작성한 CPU 검색 진단 8개(동적 근거 6개, 인물·연속성 격리 2개) 통과. 원문 4개의 원본·추출문·인용·범위 해시 모두 확인했다.
- 기존 40문항 CLI 진단은 정답 포함 29/32, 무관 질문의 빈 결과 2/8이었다. 같은 새 자료에서 호칭 정리를 끄면 30/32·2/8이었다. 빠진 1개는 실제 builder에서 고정 관계로 공급하는 근거다. 이 CLI 점수를 실제 입력 누락이나 전체 검색 정밀도 개선으로 주장하지 않는다.

채택한 카드 **v7**은 개발 진단 9개·별도 작성 진단 8개·생성된 답을 이어 쓰는 5턴 대화로 검사했다. 22개 중 정상 출력 21개, 잘림 1개다. 독립 의미 평가는 조건 충족 15개, 부분 3개, 근거 없는 과거 세부·상태 추가 3개, 출력 실패 1개였다. 호칭 반응은 개선됐지만 전체 품질 통과로 집계하지 않는다.

스토리 평가 7개 모두 정답 근거가 **동적으로 검색되어 실제 native 토큰 예산 후 입력에도 남았다**. 답변 근거 충족은 3개, 무근거 주장 추가 3개, 생성 실패 1개였다. 검색을 끈 대조 실험은 없으므로 답변의 인과적 향상을 오직 RAG 덕분이라고 단정하지 않는다.

v8은 원자 주장별 검증 지침을 추가한 비교 후보다. 일부 사실 경계 개선과 평범한 연락을 새삼스럽게 취급하는 회귀가 함께 관찰되어 운영에는 v7을 채택한다. 반복 사용한 진단을 미노출 평가라고 표시하지 않는다. 독립 검토자는 코드·이전 출력을 읽었으며 팬 검토와 통계적 우월성 검증을 대신하지 않는다.

## 남은 제한과 재현

근거 밖 동기·진행 상태, 일부 호칭 정정의 불필요한 변명, 미확인 질문의 추론 잘림은 남아 있다. 생성 품질은 [Issue #93](https://github.com/nam9nine/yaku_IPhone/issues/93)으로 추적한다. 팬 판정은 미완료다.

실제 생성 원본·메타데이터는 ignored `references/local/gemma-chat/relationship88/`의 `before`, `final-v7`, `grounding-v8`, `final-v8`에 보존했다. 최종 v7 인물 해시는 `614bbacc8af85cfd13a832ec6106f7b765c4cb6227d6b8f6bf60c3eb4da8e93d`, 레지스트리 해시는 `6c74d2d0944fb6f05c85ee8b55a6552550df8c4a4d90de7e61cecf8bc1db2290`이다. 이 기록에는 실제 방문자의 원문·토큰·비밀값을 포함하지 않았다. 최종 SHA의 독립 리뷰·검사·운영 반영은 PR 증거와 배포 기록에 별도로 연결한다.
