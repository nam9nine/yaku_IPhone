## 실제 검토와 수정

독립 에이전트 `rp_dataset_quality`가 이전 정상 실행 `b2db58574ab1ef813e0d5d93`의 원문과 정제문 285,971행을 전수 대조했다. 언어+upstreamMetadata로 원본 JSON 복원, 원문 행 해시·위치, 화자/청자 미확인, 학습 불가 상태에서 불일치 0건을 확인했다.

검토 중 같은 후보 경로가 다른 원본 컨테이너에서 충돌하는 문제를 발견했다. 그룹 해시에 container를 넣고 장면 색인에도 보존했으며 회귀 테스트와 전수 재실행을 완료했다. 최종 commit 기준 독립 검토는 PR의 harness-evidence에 기록한다.

주 에이전트가 실제 review-samples에서 미해결 변수, 미확인 color/symbol/Sign 태그, 일반 꺾쇠 표현의 원문/정제문을 직접 대조했다. 의미를 추측해 지우거나 변수 값을 만들어 넣지 않은 것을 확인했다. 이 표본은 무작위 정확도 추정이 아니다.

## 제한과 배포 범위

화자·청자·실제 사건 시점·정식 번역 일치·장면 순서 검증은 후속 라벨링 작업이다. 이름 사전과 대사 테이블의 외래키가 현재 평행 코퍼스에 없어 이름이나 번호만으로 화자를 연결하지 않는다. 니시키의 주요 원작 대화 확보에는 0/1/극1 등 추가 출처가 필요하다.

앱 UI/의존성/기준 이미지는 변경하지 않았다. 로컬 E2E·시각 비교는 미실행/미적용이며 CI의 기존 브라우저 정책은 유지한다. 원문과 정제 대사는 ignored 로컬에만 있고 앱 빌드에 포함되지 않는다. PR gate·병합·Pages 결과는 실제 확인 후 Issue/PR에 기록한다.
