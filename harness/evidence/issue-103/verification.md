# Issue 103 검증 기록

실제 생성 기록은 `references/local/gemma-chat/story103/`에 보관한다. 합성 질문·대화만 사용했으며 실사용 방문자의 원문이나 토큰·키를 옮기지 않았다. 최종 커밋의 독립 검토·실행 집계·운영 적용 결과는 PR에 남긴다.

## 변경과 감사

- 공식 SEGA 소개를 확인해 9개 관계/원작 사실을 보강했다. 실행 자료는 31개 사실·4개 장면이며 원본 1,201청크 전체의 검수·실행을 뜻하지 않는다.
- source 감사자가 신규 9개 원본 SHA·발췌 좌표·발췌 SHA를 확인했다. 보호 관계의 전체 인명과 사에지마 사건의 거역 행동까지 발췌를 보강했다.
- 특정 실패를 겨냥한 설득·공사 관련 공통 프롬프트 경고를 독립 검토 지적으로 제거했다. 모든 사실은 공통 타입·출처 범위로 읽힌다. 이름/문항 ID별 정답 분기·답변 치환은 없다.
- 사용자 지시에 따라 작품의 시간선은 지식의 제한으로 쓰지 않는다. 원작 지식과 실제 방문자 대화의 상태·약속은 구분한다.
- UI 도입의 카레·장보기 설명은 모델 입력에 넣지 않는다. 나팔꽃은 기본 위치이며 모든 대화의 주제가 아니다. 나팔꽃 정의는 고정 카드 대신 필요할 때 검색한다.
- 현재 질문의 첫 사실과 최근 문맥 후보를 함께 선택하고, 한 슬롯인 참고 장면은 문맥으로 원래 상대를 유지한다. 예산 부족 시 오래된 최근 대화가 현재 사건 근거를 먼저 밀어내지 않게 한다.

## 실험 기록의 구분

- `before`: 수정 전 실제 Gemma 13건. 실행 자체는 13건 정상 종료했지만 니시다 관계·아이들 이름/꿈·하루카의 과거 친분/현재 장소·공사 결과에 오류가 있었다.
- `after-v1`: 최초 보강 13건. 관계와 아이들 정보는 개선됐으나 동기 과장과 현재 결과의 추정이 남았다.
- `sampling-probe`: 낮은 temperature 4건. 채택하지 않았다. 공사 문항은 검색 입력도 달라 온도만의 통제 실험이 아니다.
- `grounding-v7`: 특정 경고를 늘린 4건. 공사 미확인 답은 개선됐지만 복귀 답에 새로운 배타적 원인 주장이 생겼다. 이 접근은 최종 구현에서 제거했다.
- `final-dev`, `final-additional`: 사용자 추가 요구를 반영하는 중간 검증. 각 행의 prompt/profile/registry/retriever와 정확한 input SHA로 실행 버전을 식별한다. 이 경로 이름만으로 최종 배포 SHA 검증이라고 주장하지 않는다.
- 마지막 고정 소스의 검사와 실제 반영 결과는 PR에서 별도 집계한다. 생성 성공률과 의미 정확성·말투 판정은 서로 다르며 팬 검토는 미완료다.

## 제한

입력 상한 3,072, 전체 문맥 6,144, thinking 자연 종료, 생성 상한 3,072 및 기존 샘플링을 유지한다. 2,048 입력 예산 탐색에서 일부 필요한 자료가 빠지는 사례를 확인해 운영 상한을 줄이지 않았다. 검색/토큰 생존/최종 답변 정확도를 별도로 본다. 반복 통과가 전 시리즈를 완벽하게 안다는 증거는 아니며, 새 표현과 명시적 완료 보고·미완료 계획의 반대 조건도 검증한다.

## 후속 연구 기반 원작 RAG

위 기록은 첫 수정의 실제 실행 기록이다. 이후 Contextual Retrieval·LongMemEval·HippoRAG2·RARR·E5 공식 문서를 검토하고 출처52개, 읽기 단계, 실패 감사·예산 보호를 추가했다. 연구 스냅샷 색인은 `research-sources.json`, 보존한 중간 비교는 `rag-evaluation-checkpoints.json`, 기존40문항 검색 단계 검사는 `retrieval40.json`이다. 최종 코드와 같은 소스 해시를 사용한 실제 Gemma 내용 결과·배포 확인은 PR #104의 완료 검증 댓글과 로컬 `references/local/gemma-chat/rag-research/`에 남긴다. 중간 비교를 최종 배포 판정으로 읽지 않는다.
