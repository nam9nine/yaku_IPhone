# Issue 103: 원작 기억과 관계 검증

목표는 하루카·마지마의 승인된 원작 관계/사건과 방문자 기억을 작은 입력 예산에서 정확히 사용하는 것이다. 전 시리즈를 모두 기억한다고 판정하지 않는다.

1. 기존 22사실·4장면과 실제 Gemma 모델의 기준 답변을 보존한다.
2. 공식 근거로 인물 관계/과거 사건을 추가하되 현재 상태·IF·다른 인물의 비밀과 구분한다.
3. 현재 질문과 관계에 필요한 사실이 오래된 대화 때문에 입력에서 제거되는지 검사한다.
4. 개발 문항 → 수정 → 같은 조건 재검증 → 사전 고정 독립 문항을 실행한다. 기본 모델/샘플링/생성 예산을 유지한다.
5. 원문 답변·실제 최종 입력·검색 근거·제외된 ID·토큰 수를 저장하고 실패를 포함해 의미를 판정한다. CPU 격리·정정 회귀와 독립 코드 리뷰를 진행한다.
6. 검증된 변경을 PR·운영 API에 반영하고 실제 연결을 확인한다. 미해결 생성 오류와 팬 검토는 별도로 남긴다.

실행 결과는 검증 후 evidence에 기록한다. 실사용 메시지를 평가에 복사하지 않고 합성 방문자만 사용한다. 모델 프로세스의 비공개 thought는 저장하지 않는다.

## 작업 중 확정된 사용자 방향

- 작품 시간선은 지식 제한에 사용하지 않는다. 원작 출처와 방문자 대화의 현재 상태는 별도다.
- 특정 오답 단어를 막는 경고를 늘리지 않는다. 모든 사실에 공통 타입·범위를 적용하고 같은 검색기를 사용한다.
- 나팔꽃·장보기 도입으로 모든 대화의 주제를 고정하지 않는다. 시작 장소와 대화 주제를 구분하고 UI 도입 문장은 모델 입력에서 제외한다.
- 회귀 문항과 구현에서 분리해 사전 고정한 추가 문항의 성적을 구분하고, 평가에 노출된 뒤 수정한 경우 기록한다.
