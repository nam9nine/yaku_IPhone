# Issue 46: 막대 없는 하단 제스처와 자연스러운 곡선

원본: [Issue 46](https://github.com/nam9nine/yaku_IPhone/issues/46).

## 확정한 범위

- 하단 흰색/검정색 장식 막대를 홈·앱·시스템 패널·통화에서 제거한다. 기존 입력 영역·safe area·키보드 대체 조작은 유지한다.
- 사용자가 확인한 “왼쪽에서 출발해 위쪽으로 휘어 올리는 곡선”과 기존 직선 상승을 함께 지원한다. 처음 옆으로 움직인 곡선과 마지막 구간이 옆으로 향하는 사분원도 포함한다.
- 하단은 작은 상승 후에도 최근 앱으로 진입할 수 있게 하되 빠른 release=홈, 느린 이동/멈춤=최근 앱, 끝까지 상승=홈을 유지한다.
- 최근 카드의 곡선 삭제는 같은 방향 판정을 사용한다. 삭제 거리 96px와 가로 탐색을 유지해 작은 흔들림으로 닫지 않는다.
- 사용자가 요청한 나가기 버튼 전반을 검사한다. 재현된 상단 pull/edge navigation의 버튼 입력 탈취를 좁게 수정한다.
- 앱 구조·레이아웃·새 기능을 재설계하지 않는다. 실제 iPhone Safari 확인 여부는 별도로 기록한다.

## 구현과 확인 순서

1. 공유 막대 컴포넌트와 통화 장식을 제거하고 기존 터치 영역을 유지한다.
2. 최근 이동 경로와 누적 상승의 공통 판정을 만든다. 축 전환·가로 탐색·짧은 취소·사분원·입력 빈도를 단위 검사한다.
3. 짧은 상승의 연속적인 축소와 미리보기를 적용한다. 카드의 상향 이동은 해당 카드만 가로로 움직이게 한다.
4. 버튼 중심에서 아래/오른쪽 9px 움직이는 실제 브라우저 입력으로 복귀 동작을 검사한다. 상단 pull과 edge navigation이 버튼·링크의 작은 탭을 가로채지 않도록 하고 명확한 긴 드래그는 유지한다.
5. 전체 경로 시간을 고정한 trusted 입력으로 빠른/느린/멈춘 직선·곡선·카드 취소를 검사한다. 기존 resize·다중 입력·키보드·스크롤 검사를 함께 실행한다.
6. 조정 에이전트가 360×800, 390×844, 430×932의 실제 캡처와 baseline 차이를 직접 검토한다. 독립 리뷰·최종 검사·PR·병합·배포는 조정 에이전트가 수행한다.

## 검증 명령

- `npm run check`
- `npm run test:e2e -- tests/browser/natural-gestures.spec.ts tests/browser/motion.spec.ts tests/browser/system.spec.ts tests/browser/shell.spec.ts tests/browser/app-navigation.spec.ts tests/browser/desktop.spec.ts`
- 최종 전체 e2e·시각 회귀·독립 리뷰·배포 결과는 실행 뒤 증거에 기록한다. 계획 자체를 통과 증거로 사용하지 않는다.

## 협업 경계

구현은 지정 `natural-gestures` worktree에서만 수행한다. 기본 폴더와 다른 작업자의 worktree를 변경하지 않는다. Git·baseline·증거·최신 main 통합은 조정 에이전트가 담당한다.
