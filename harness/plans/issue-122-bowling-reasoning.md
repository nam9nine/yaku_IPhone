# Issue #122: 볼링 원작 근거와 자유 대화 판단

## 목적

원작의 볼링 승부 동기를 승인 자료로 연결하고, 이번 방문자의 실제 초대·답변·통화 결과와 구분한다. 추가 학습이나 정답 문구 분기 없이 기존 Gemma reader와 답장 생성기를 확장한다.

## 구현 순서

1. 원문 발신자·출처·발췌 위치·해시와 직접 문자로 바꾼 IF 각색을 기록한다.
2. 사건 전용 근거를 승인·인물·시나리오 필터 안에서 선택한다.
3. 사건 상태와 선제 발신 타임라인을 실제 user/assistant 쌍과 구분해 입력한다.
4. reader 판단을 현재 메시지 ID·사건 버전에 묶고 답장 생성 전에 저장한다.
5. 원문은 DB에 보존하고 모델 입력에는 중복 없는 예산 제한 문맥을 제공한다.

## 검증

- 통화 결과, 짧은 지시어, 취소와 모호한 응답, 승인 자료 격리, native 토큰 예산을 검사한다.
- `ai/chat/bowling-evaluation.json`의 사전 고정 12개 상황을 실제 API·DB·Gemma로 각 4턴 이상 실행한다.
- 판단 10/12 이상, 취소 무시와 원작/방문자 경험 혼동 0건을 확인한다. 말투와 팬 검토는 별도로 기록한다.
- 실패 출력도 보관하고 수정 전 결과를 통과 결과로 바꾸지 않는다.

실행 결과는 로컬 평가 산출물과 PR 증거에 기록한다. 이 계획은 검증 완료 기록이 아니다.
