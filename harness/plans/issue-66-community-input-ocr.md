# Issue 66: 대화 입력 변환과 한국어 OCR

## 목표

수집된 196개 원문 후보를 화자 관계를 보존하는 모델 입력으로 변환한다. 4,564개 이미지 출처 연결(고유 URL 4,561개)을 다운로드하고 접근 가능한 이미지를 Apple Vision으로 OCR한다. 원문 이어쓰기와 실제 문자 입력 각색은 별도 과제·출력으로 구분한다.

## 실행 순서

1. 입력·원문·분할 SHA를 고정하고 별도 worktree에서 구현한다.
2. 재개 가능한 이미지 수집과 이미지 내용 SHA 기준 중복 제거를 수행한다. 접근 거부·반복 오류는 중단 사유를 남긴다.
3. Vision accurate revision 3, ko-KR/en-US, 언어 보정 비활성화로 텍스트·좌표·신뢰도를 저장한다. 화자를 추측하거나 학습을 자동 승인하지 않는다.
4. 원문 196개를 화자명이 포함된 기록과 마지막 답변으로 변환한다. 현재 앱의 키류 상대 프로필을 원문에 적용하지 않는다.
5. train 원문만 참고한 일반 문자 입력 각색은 원문과 별도로 보관한다. 새로운 문장·관계 변경을 명시하고 원작 인용으로 표시하지 않는다.
6. 실제 Qwen 토크나이저로 추론 접두부, 답변·종료 토큰, 패딩 제외, 길이를 검사한다. 기존 200개 학습 파일과 서빙 모델은 보존한다.
7. 자동 검사와 독립 검토, PR gate, 병합 및 배포 확인을 진행한다.

## 검증과 한계

원문 대조, 출처·분할·화자 관계 검증, OCR 실제 이미지 비교, 실패 상태 집계, Python 테스트 및 npm check를 실행한다. UI 변경은 없다. OCR 신뢰도는 화자·번역·인물성 검수를 대신하지 않는다. 실제 팬 평가는 미완료로 유지한다. 데이터 수량과 실행 결과는 로컬 실행 보고서와 Issue에 기록하며 이 계획에 성공을 미리 기재하지 않는다.
