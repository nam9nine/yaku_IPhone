# Issue 56 — 자료 수집·QLoRA·로컬 추론

## 목표와 범위

M5·24GB에서 한국어 캐릭터 문자 데이터 수집, 검수, 학습, 저장본 재로드,
실제 추론까지 실행한다. 학습·검수·추론 대상은 마지마·하루카 두 명이다.
다른 인물의 참고 자료는 별도로 보관하며 이번 학습에 포함하지 않는다.
원문·학습 자료·모델은 ignored 로컬에 두며 앱 번들에 포함하지 않는다.
공개 앱 연결과 외부 추론 서버 개방은 이번 범위가 아니다.

## 확정한 기준

- 공식 자료와 접근 조건을 확인한 자료를 수집한다. 팬 번역·전사와 공식 현지화를 구분한다.
- 원작 화자·상대·순서가 미확인된 기존 후보를 자동으로 정답으로 만들지 않는다.
- 새 IF 대화는 authored_if로 기록한다. 교사 작성, 독립 에이전트 검수, 팬 평가를 분리한다.
- 사용자는 원작 근거·에이전트 검수로 실험 학습을 진행하고 실제 추론 이후 팬 평가를 하는 순서를 선택했다.
- Qwen3.5 9B/4B 4bit, MLX-LM 0.32.2, Python 3.12.13을 사용하고 환경을 잠근다.
- 공식 non-thinking 템플릿을 사용한다. 패딩과 다음 토큰 이동 후 마지막 답변·종료 토큰만 손실 대상으로 삼는다.
- 2 epoch는 첫 실험 예산이다. 무효과를 방법 전체의 실패로 판정하지 않고 구현·적응·일반화를 구분한다.
- 저장한 어댑터를 다시 로드해 평가하고 파일 해시와 실행 결과를 연결한다.
- 학습 효과가 불명확하면 기본 모델도 제품 후보로 유지한다. 팬 검수 전에는 제품 품질 통과를 주장하지 않는다.

## 순서와 검증

1. 별도 worktree와 로컬 Python 환경을 준비하고 고정 모델을 받는다.
2. 작품별 자료와 두 인물 설정을 수집하고 출처·범위·실패를 기록한다.
3. 대화·상황 그룹 단위 분할과 교사 예시를 생성하고 독립 검토한다.
4. 순수 인덱스 검사, 실제 토크나이저 경계 검사, 작은 학습 진단을 수행한다.
5. 메모리와 실행 시간을 관찰하며 파일럿 학습과 기본/어댑터 추론을 수행한다.
6. 문맥 조건별 평가, 입력·상태 격리, 저장·재로드 및 요청 처리 시간을 기록한다.
7. 코드 검사와 독립 리뷰 후 PR·필수 gate·병합·배포 상태를 확인한다.

## 성공과 미완료의 구분

코드·자료의 형식 검사, 실제 학습 실행, 모델 품질, 팬 평가, 공개 제품 연결은
서로 다른 판정이다. 실행하지 않은 항목이나 기준에 미달한 결과를 성공으로 기록하지 않는다.
기준 미달 시 관측한 실패와 재현 방법을 남긴다. 이 계획은 실행 성공 증거가 아니다.
