# Issue 90 답장 알림 누락과 수신음

## 목표

구독이 있다는 이유로 사이트 배너를 없애는 문제와 가려진 배너의 표시 시간이 소진되는 문제를 고친다. 현재 대화와 다른 화면의 수신음을 구분하고 클래식 Tri-Tone 참고 합성음을 추가한다.

## 구현과 검증 계획

1. 배너·OS Push·소리의 책임을 분리하고 구독 여부만으로 전달 성공을 판단하지 않는다.
2. 새 답장 표시 이벤트와 읽지 않은 알림을 분리해 현재 대화에서도 수신음을 낸다.
3. OS Push의 userVisibleOnly와 초기화 격리를 유지하고 foreground/복귀 중복음을 막는다.
4. 권한·API 모의 환경에서 Chromium/WebKit 360/390/430, 가림·무음·복귀·새로고침을 검사한다.
5. 캡처를 직접 검토하고 기존 자동 검사·독립 리뷰·PR·공개 배포로 전달한다.

원본 Apple 음원은 로컬 참고에만 사용하며 앱에는 직접 합성 코드를 넣는다. 실제 iPhone 검증 여부와 실행 결과는 계획이 아니라 별도 증거에 기록한다.
