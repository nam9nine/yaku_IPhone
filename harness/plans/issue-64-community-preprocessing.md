# Issue #64: 한국어 커뮤니티 자료 전처리

## 목표

마지마·하루카·키류 자료를 출처와 실제 이전 문맥을 보존한 검수 후보로 만든다. 원문 번역을 기존 IF 창작 데이터로 위장하거나 운영 모델에 자동 반영하지 않는다.

## 단계

1. 저장된 DC 원문의 해시와 분류를 확인하고 신규 한국어 번역 본문을 확보한다.
2. 공통 입력 문서와 사건 그룹을 구성한다. 동명이인·가짜 키류·연기·팬 창작·이미지 미전사 자료를 별도 분류한다.
3. 오프라인 전처리 명령으로 발화·장면·이전 문맥·RAG 근거 후보·보류 및 중복 기록을 만든다.
4. 원문 좌표, 불확실한 이어말하기, 문맥 누출, 동일 사건 분할, 재현성을 검사한다.
5. 실제 자료를 처리하고 독립 검토를 거친 뒤 PR gate와 배포를 확인한다.

## 완료 범위와 제한

이번 단계는 텍스트 전처리다. 전체 이미지 OCR, 팬 평가, SMS 각색, 학습 승인과 모델 재학습은 포함하지 않는다. 기존 데이터·모델·앱은 보존하며 원문/로컬 생성물은 공개 Git에 넣지 않는다. 후보 수와 승인·학습 export 수를 별도로 기록한다.

## 검증

- Python 단위 검사: 원문 해시, 줄 좌표, 독백·선택지·미상 화자, 중복/사건 분할, 미래 답변 누출, 재실행 일치.
- 실제 데이터: 입력별 처리/보류 수, 원문 역참조, 세 인물별 후보와 제한.
- `npm run check`, Python lint/format/전체 검사.
- UI 변경 없음: 시각 검토 미적용 이유를 PR에 기록한다.
