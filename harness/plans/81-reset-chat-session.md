# Issue 81: 폰 초기화와 AI 세션 분리

설정에서 초기화를 확인하면 새 익명 방문자 세션으로 전환한다. 기존 SQLite 원문,
생성 결과, 검색 근거, 검토는 보존하고 새 대화의 최근 이력·장기 기억에서 제외한다.
서버 스키마와 API 변경 없이 기존 방문자 격리 계약을 사용한다.

1. localStorage 초기화 경계를 먼저 확정한다. 실패 시 초기화를 중단한다.
2. 현재·레거시 토큰과 늦은 응답을 경계로 차단하고 다른 열린 탭도 전환한다.
3. Web Locks로 동시에 열린 탭의 새 세션 발급을 직렬화한다.
4. 취소·초기화·새로고침·여러 탭·저장 거부·늦은 응답 및 DB 보존을 검증한다.
5. 추가 사용자 요청에 따라 메시지의 이전 대화 라벨·저장 안내를 제거한다.
6. 화면 직접 검토와 독립 리뷰 후 배포한다. 필수 PR gate를 유지하고, 배포 단계는
   요청된 기존 local_verified 수동 경로로 중복 검사를 생략한다.

실행 결과는 별도 증거와 Issue에 남긴다. 새 세션에는 고정 원작 RAG와 기본 스토리
시작 장면이 유지된다. 서버의 기존 토큰을 폐기하는 기능이나 대화 삭제가 아니다.
