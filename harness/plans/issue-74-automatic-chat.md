# Issue #74 · 무설정 접속과 공개 Gemma 통합

기존 Pages 주소와 메시지 화면을 유지하면서 고정 Worker/VPC/Tunnel API에 자동 연결한다. 운영자와 방문자의 설정을 분리하고 실제 대화 원문을 SQLite에 접수 시점부터 보존한다.

1. 익명 세션·UUID 중복 방지·범위별 이력·FIFO 작업 API를 기존 DB/추론/검색 기반에 연결한다.
2. 고정 Worker의 공개 경로와 Origin·본문 한도를 검증하고 QUIC Tunnel을 chat 포트에만 연결한다.
3. 임의 endpoint·초대 연결 UI를 제거하고 자동 복원·만료 갱신·오류 재시도·저장 안내를 구현한다.
4. 실제 20개 다중턴 대화와 두 30턴 대화, 조건 쌍을 실행하고 검색·답변 품질을 분리 검토한다.
5. 준비된 모델 60요청과 2·4명 도착을 별도 측정한다. 처리 시간·대기·실제 출력 길이·시스템 swap을 기록한다.
6. 합성 API fixture의 브라우저·시각 회귀와 실제 공개 Pages의 두 인물 답장을 확인한다.
7. 최종 diff·캡처·기준 변경의 독립 리뷰와 필수 gate 후 병합하고 main 배포를 검증한다.

성공 여부와 알려진 품질 한계는 실행 후 증거에 기록한다. 팬 검토·실제 iPhone Safari 확인을 에이전트나 데스크톱 WebKit 결과로 대체하지 않는다. 서비스 실행기는 자신이 시작한 프로세스만 소유하며 다른 작업자의 프로그램을 종료하지 않는다.
