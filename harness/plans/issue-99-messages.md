# Issue 99 — 메시지 화면과 소리

사용자 제공 실기기 캡처를 기준으로 전체 불투명 상단바를 제거하고 상단 대화 흐림과 떠 있는 프로필·이름·뒤로·알림 버튼을 구현한다. 키보드 자체 크기는 OS가 정하므로 visualViewport 끝에 입력창을 붙이고 중복 safe area와 하단 제스처 띠를 제거한다. 키보드를 닫으면 제스처를 복원한다.

1. 전송음은 요청한 기존 대화 효과음을 재사용한다.
2. 전경 PWA Push는 준비된 페이지의 실제 재생 claim을 먼저 시도한다. 불가능하면 OS 경로로 돌아간다.
3. 무음·숨김·초기화·다중 창 취소와 중복 억제를 검증한다.
4. 360/390/430px 및 키보드 축소 뷰포트, 밝음/어두움에서 직접 캡처를 검토한다.
5. 사용자 요청으로 CI 없이 로컬 관련 검사·독립 리뷰 후 PR과 수동 Pages 배포를 진행한다.

실제 iPhone 키보드와 설치 앱 스피커를 직접 확인한 것으로 보고하지 않는다. 상태바의 배터리 80은 기존 가상 값이며 실제 기기 값을 읽는 기능을 추가하지 않는다. 네이티브 상태바가 있는 설치 앱에는 기존 중복 방지 규칙을 유지한다.
