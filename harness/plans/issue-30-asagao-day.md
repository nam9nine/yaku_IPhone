# Issue 30: 나팔꽃의 평범한 하루

## 목표와 우선순위

기존 React/Vite/TypeScript와 앱·제스처를 유지하며 생활 속 개인 휴대폰으로 구성한다.
최신 사용자 보정에 따라 iOS 18로 한정한 재디자인은 하지 않고 기존 iPhone 스타일을 유지한다.
카레 알림 → 대화 → 메모 → 장보기/위젯 → 답장을 먼저 연결하고 사진·나머지 앱을 통합한다.

## 구현 계약

- React DayProvider의 단일 상태가 재료, 할 일, 읽음, 선택형 답장, 한 번의 부재중 전화를 소유한다.
- 장보기 완료와 남은 개수는 체크 네 개에서 파생한다. 시간 경과가 이벤트를 진행하지 않는다.
- 설정은 기존 저장을 확장하고 배경별 위치를 보관한다. 사진과 잠금/홈은 같은 미디어 색인을 쓴다.
- 데모 시각은 토요일 2026-10-24 16:40, 날씨 27°. 실제 연대나 실시간 데이터를 주장하지 않는다.
- 알림·위젯은 실제 앱/내용으로 이동한다. 기존 홈/최근 앱/뒤로 가기/취소·접근성을 유지한다.
- PC에만 외곽 프레임을 두고 모바일은 기존 전체 화면을 유지한다.
- 허가 미확인 게임 이미지를 생활사진으로 재사용하지 않는다. 교체형 로컬 임시 자료와 목록을 제공한다.

## 담당

- 주 에이전트: 통합, 잠금/홈/전화/설정/배경/PC 레이아웃, 검사, Git/Issue/PR/배포.
- core worktree: 공유 상태, 메시지/메모/미리 알림/캘린더와 단위 검사.
- media worktree: 사진, 임시 자산, Safari 가상 콘텐츠, 자산 문서.
- 독립 검토자: 참고 자료 조사와 최종 diff/화면/완료 조건 검토. 구현에는 참여하지 않는다.

## 검증 계획

카레 전체 흐름·중복 방지·읽음/배경/체크 복원·저장 실패·확인 취소와 초기화·권한 호출 없음,
모바일 360/390/430과 PC의 프레임/제스처 좌표, 기존 제스처와 Safari 기본 탐색을 검증한다.
제품 캡처를 직접 비교하고 플랫폼별 기준 변경은 독립 검토 뒤 등록한다.
실제 명령 결과는 별도 evidence와 PR 현재 SHA에 기록한다. 이 계획에는 성공을 미리 적지 않는다.
