# Issue 24 — 키류의 폰

연락처·메시지·메모·사진을 하나의 연결된 결과로 구현한다. 특정 정사 연도를 고정하지 않고 요청된 인물이 모두 있는 팬 창작 설정이다. UI는 Apple 공식 화면을 기준으로 하고 게임 사실·이미지는 SEGA 공식 자료에서 확인한다.

1. 공식 인물·나팔꽃·앱 화면 조사와 자산 확보.
2. 독립 worktree에서 연락처/메시지, 메모/사진을 나누고 주 에이전트가 공통 shell·영속 저장·데이터·검사를 담당.
3. 세로 본문 스크롤, 한 단계 뒤로, 최근 앱, 키보드·reduced motion·safe area를 연결.
4. 모든 연락처에 로컬 메시지 전송, 메모 수정/체크/생성/삭제, 사진 보기/즐겨찾기를 검증. 저장 오류·손상 복구와 새로고침 보존을 포함.
5. 3크기 두 엔진 캡처를 직접 열어 Apple 기준과 비교. 양 플랫폼 baseline은 독립 검토 후 등록.
6. 구현하지 않은 검토자가 최종 diff·조건·이미지 확인. 현재 SHA 증거를 PR에 연결하고 필수 gate → squash → Pages → 공개 조작.

실제 SMS/전화, 서버·계정·AI 자동 답장은 범위 밖이다. 저장은 이 브라우저에 한정하며 실제 iPhone Safari는 별도 미검증이다. 실행 결과는 이 계획에 미리 성공으로 적지 않는다.
