# Issue 13 기본 설정 연결

## 목표와 범위

공통 앱 창에 설정 목록·상세 화면을 연결한다. 설정만 버전별 localStorage에 보관하며 앱의 상세 화면·스크롤은 세션 동안 유지한다. 가상 연결 모델과 실제 웹 UI의 테마·밝기·배경·텍스트·동작을 구분한다.

## 구현과 검증

1. 연결 모델·저장소 경계의 단위 검사를 유지하고 설정 컴포넌트를 연결한다.
2. 시스템 테마/동작 줄이기를 구독하고 안전한 범위의 밝기 덮개·배경·rem 글자 크기를 적용한다.
3. Chromium/WebKit에서 연결/저장 실패/복원/재진입/전역 효과/본문 입력 충돌과 세 크기를 검사한다.
4. 공식 설정 자료와 실제 캡처를 직접 비교한다. 기존 잠금/홈 baseline은 기본 설정에서 유지되어야 한다.
5. 최종 SHA 독립 리뷰·CI·squash 병합·main Pages 확인 결과를 별도 증거에 기록한다.

실제 기기 설정 변경, 검색/페어링, 계정과 상세 설정은 범위 밖이다. Safari 연결 소비는 Issue 14에서 이어진다. 실제 iPhone Safari는 미확인 상태를 유지한다.
