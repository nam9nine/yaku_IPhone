# Issue 33 — 실사용 앱 화면과 상단 드래그

목표는 사용자가 제공한 최근 통화·연락처·키패드·설정 캡처의 구성을 기존 앱에 반영하는 것이다. 다크와 라이트 설정을 유지하며 최신 요청에 따라 시간·Wi-Fi·통신 신호·배터리 상태표시줄도 웹 안에 표시한다. 개인정보는 키류 세계관의 창작 연락처로 대체한다.

1. 전화의 다섯 탭, 연락처 검색/상세/내 카드, 별도 홈 아이콘과 설정 프로필을 구현한다.
2. 공식 공개 게임 장면을 로컬 저장하고 출처/해시/권리 상태를 남긴다. 갤러리에서 임의 생활 사진을 제거한다. 기존 배경 선택은 유효한 게임 이미지로 호환한다.
3. 상단 시작 영역을 웹 화면 안쪽으로 내리고 패널이 드래그를 추적하게 한다. 입력/버튼과 설정 본문 스크롤을 가로채지 않고 취소·크기 변경·reduced motion을 검사한다.
4. 장보기의 한 번뿐인 마지마 이벤트를 수신 연출로 확장한다. 응답/거절/시간 초과를 구분하고 알림/기록/배지를 같은 상태로 갱신한다. 실제 전화나 오디오는 사용하지 않는다.
5. 관련 상태 전환과 브라우저 검사를 추가하고, 세 크기의 두 엔진 실제 캡처를 사용자 자료와 직접 비교한다. 독립 리뷰 후 플랫폼별 기준 이미지를 승인한다.
6. 현재 SHA의 필수 검사와 증거를 연결해 squash 병합하고 Pages의 자산·상호작용을 확인한다.

불확실성: 모바일 Safari의 네이티브 가장자리 제스처는 웹에서 완전히 제어할 수 없다. 웹 내부에서 시작하도록 바꾸되 실제 기기 확인 여부는 따로 기록한다. 사용자 첨부 스크린샷은 대화에서 확인했으며 로컬 원본 파일이 있다고 주장하지 않는다. 공식 게임 이미지는 공개 출처이며 오픈 라이선스로 간주하지 않는다.

이 파일은 실행 계획이며 통과 기록이 아니다.
