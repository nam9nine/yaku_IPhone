# Issue 37 — 상단 터치 복구와 몰입을 방해하는 안내 제거

1. 잠금·홈·설정에서 네이티브 터치로 하향 입력을 재현한다. 자식의 implicit pointer capture를 shell로 넘길 때 발생하는 lostpointercapture를 전체 취소로 오인하는지 확인한다.
2. 소유한 capture의 손실만 취소로 처리한다. 상태바와 기존 40–112px 시작 영역을 지원하고, 버튼 탭·본문 스크롤·가로 제스처·짧은 드래그·취소는 보존한다.
3. 설정 데모 페이지와 사진 출처 UI를 제거한다. 다른 앱의 팬메이드·웹 체험 설명도 제거하고 필요한 연결/저장 실패 상태만 간결하게 남긴다. 출처·권리와 가상 데이터 설정은 references/ 및 문서에 보관한다.
4. 실제 터치 회귀 검사, 두 엔진 전체 검사와 의도한 화면 변경의 플랫폼별 기준 비교·독립 검토를 수행한다.
5. 현재 SHA의 증거로 필수 gate를 통과하고 squash 병합·Pages 공개 조작까지 확인한다.

이 문서는 계획이며 성공 판정은 실행 결과에 별도로 기록한다.
