# Issue 68: 검수된 한국어 학습 자료와 전 시리즈 스토리 참고 자료

## 범위와 원칙

기존 텍스트196개, 문자 각색24개, 수집 이미지4,316개를 출처별로 관리한다. 한국어 실제 인용, 한국어 팬 번역, 한국어 패치 화면, 새 IF 문장을 구분한다. 원문과 OCR를 보존하고 교정·화자·문맥 판정에 근거와 해시를 연결한다. 일본어는 한국어 말투 학습에서 제외한다.

시나리오는 2026-10-26 공식 출시 목록을 기준으로 본편·리메이크의 추가 시나리오·외전·파생작을 조사한다. 공식 개요, 전체 줄거리 요약, 장별 요약, 대본을 별도 확보 수준으로 표시한다. 모든 작품을 목록에 포함한 것과 모든 장·부가 이벤트를 확보한 것은 다른 결과다. 접근 불가와 자료 미발견을 숨기지 않는다.

## 작업

1. 현재 데이터·출시 목록·기존 학습 및 런타임 계약을 읽고 누락과 위험을 기록한다.
2. 원문196개의 의미·화자·문맥을 검토하고 승인/보류/제외를 기록한다. 이미지를 실제로 열어 OCR를 교정하며 명시적 이름표·장면 단서를 우선 확인한다.
3. 검수된 원문 이어쓰기와 SMS 각색을 별도 학습 파일로 내보낸다. 수신인 불명을 키류로 바꾸지 않는다. 화자·문맥이 확인되지 않은 OCR는 학습에 넣지 않는다.
4. 작품별 스토리 원문·출처·판본·세계관을 보존하고 원문 범위에 연결된 RAG 청크와 오프라인 검색 인덱스를 만든다. 현재 캐릭터 기억과 서비스에는 자동 연결하지 않는다.
5. 해시·검수 범위·분할·토큰/패딩·검색 필터·자료 확보 범위를 검사한다. 미검수를 검토 보류로 바꿔 완료라고 계산하지 않는다.
6. 독립 코드/데이터 검토, PR 검사, 병합과 배포 확인을 수행한다.

## 담당

조정 에이전트가 통합 worktree에서 exporter·검색·검사·문서를 구현한다. 독립 worktree에서 원문/이미지 검수와 시리즈 자료 수집을 병렬 진행한다. Git mutation은 조정 에이전트만 한다. 원본과 대용량 산출물은 ignored 로컬 경로에 보관한다.

## 검증

변경된 원문·교정·프로필·리뷰의 승인 무효화, 과제 간 관계 왜곡 차단, split 누수 차단, 미검수·타언어·비대사 배제, 원문에서 RAG span 재현, 작품/판본/세계관 검색 필터를 검사한다. 실제 Qwen 템플릿과 loss mask를 검증한다. 모델 학습·서빙 교체는 이번 작업에 포함하지 않는다. 에이전트 검수와 팬 검수는 구분한다.
