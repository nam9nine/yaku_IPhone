# Issue 88: 키류–마지마 호칭과 검색 근거

목표는 키류의 익숙한 `형님` 호칭을 낯선 예의로 해석하는 오류를 고치고, 두 인물의 과거 사건을 실제 검색으로 전달하는 것이다. 다른 인물 관계·학습·전 시리즈 원문 전체 승격은 제외한다.

1. 원본 DB에서 호칭 실패를 읽기 전용으로 확인한다. 기존 응답은 수정하지 않는다.
2. 한국어 게임 캡처와 SEGA·PlayStation 공식 자료를 대조한다. 명패·호칭 방향·원문 범위·해시·원작과 IF 해석을 구분한다.
3. 호칭·관계는 고정 입력, 동성회 복귀·건설 도움은 동적 검색으로 채택한다. 원문 장면은 화자 정보를 유지한 검색 문서로 색인한다.
4. 변경 전 개발 진단을 고정하고 같은 모델·생성 조건으로 변경 후 답변을 비교한다. 별도 에이전트 작성 진단은 새 출력 확인 전 고정한다.
5. 고정 근거/검색 후보/실제 토큰 예산 후 근거/최종 답변을 나눠 평가한다. 자료가 없는 질문은 답변의 구체적인 창작 여부를 확인한다.
6. 단위 검사·원문 검토·독립 diff/결과 리뷰·필수 gate 후 병합한다. 운영 API만 안전하게 갱신하고 공개 주소의 새 대화를 확인한다.

계획은 실행 성공 기록이 아니다. 팬 품질과 실제 추론 성공을 구분하고, 기존 1,201개 원문 청크는 승인된 실행 자료와 섞지 않는다.
