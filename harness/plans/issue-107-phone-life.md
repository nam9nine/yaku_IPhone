같은 연락처는 답장을 기다리는 동안1개만 접수한다. 다른 연락처는 즉시 접수하되 모델은 순서대로 생성한다. 점말풍선은 없애고 읽음·지연 전달·실제 도착 알림은 유지한다.

하루카는 퀘스트 중심 선택지를 Gemma에 보내고, 마지마는 자유 문자와 선택지 구간을 섞는다. 비AI 연락처는3차례 선택형 왕복을 제공한다. 고정 대사는 팬 창작으로 관리하고 원작 인용이나 실제 AI 생성으로 표시하지 않는다.

인연은 -5~5의 작은 범위에서 명시적 선택과 상호작용으로 변한다. AI에는 warm/neutral/cool 값만 전달하며, 이 값으로 원작 관계·화자·과거 사실을 바꾸지 않는다. 전화 간격/인연 수치는 구현 기본값이며 확정된 팬 요구라고 기록하지 않는다. 배경·잠금·통화 중에는 새 자동 수신을 억제하고, 새로고침에 놓친 전화를 몰아서 재생하지 않는다.

## 최신 사용자 조건

2026-10-29: 여러 연락처에 문자 접수는 허용하되 추론은 한 건씩 접수 순서대로 실행한다. 긴 대기는 허용한다. 방문자별 병렬 모델이나 다중 생성 슬롯을 만들지 않으며 모든 방문자가 하나의 FIFO·추론 worker를 공유하는지 검사한다.

추가 조건: 마지마 선제 문자·전화를 활성 사용 중 수시로 제공한다. 고정 IF 대본은 인물별 사건으로 전달하며 AI 생성 문자와 구분한다. 중복·대기 충돌·재접속 몰아보내기를 검사한다.

음성 추가 조건: 캐릭터 음성 출력은 계속 폐기하되 사용자의 실제 한국어 음성을 브라우저에서 인식한다. 마지마·하루카 통화에서 인식 결과 확인·수정·명시 전송 후 기존 Gemma가 글로 답한다. 권한 거절·미지원·종료/숨김·이전 대기 답장·연결 준비 중 재시도를 검사한다. 대체 API 이벤트 검사와 실제 음성 인식 성공 여부를 분리 기록한다.
