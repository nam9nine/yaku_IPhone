# Issue 14 Safari 기본 탐색과 통합 시각 검증

## 목표

홈에서 여는 Compact Safari에 시작 화면·내부 페이지 두 개·제목 검색·주소 입력·탭별 탐색과 오프라인 재시도를 연결한다. 외부 http(s) 주소는 사용자에게 안내하고 명시적인 새 탭 링크로만 연다.

## 실행 순서

1. 세션 reducer와 두 내부 문서, Compact 조작을 통합하고 가상 네트워크 상태를 전달한다.
2. 사용자 이벤트에서 동기 포커스로 주소 입력을 열며 app viewport가 줄어도 이동/취소/홈 조작을 보존한다. 실제 iPhone 키보드 확인과 desktop resize 검사를 구분한다.
3. 페이지 메뉴는 앱 본문 안에 표시하여 공통 홈 조작을 막지 않고 웹 밝기 효과도 적용한다.
4. 양 엔진에서 탐색/탭/scroll/재진입/연결 복구/키보드/메뉴 중 홈 복귀를 검사한다.
5. 실제 캡처와 공식 Compact/시작/탭 화면을 직접 비교한 뒤 설정·Safari의 최초 기준 이미지를 추가한다. 기존 baseline은 바꾸지 않는다. Linux 최초 baseline은 CI 캡처를 직접 검토한 뒤 등록하며 누락 중 gate는 실패로 유지한다.
6. 최종 SHA 독립 리뷰·필수 gate·squash 병합·공개 Pages에서 두 앱의 이어지는 동작을 확인한다.

외부 iframe/프록시/서버, 앱 전환기·제어센터·계정·방문 기록 관리·즐겨찾기는 추가하지 않는다.
