# Issue 26 — 실제 사용 화면과 연속적인 모션

빠른 하단 상승은 홈, 느린 중간 상승과 멈춤은 최근 앱으로 구분한다. 추가 요구대로 손가락이 중간에 있을 때 카드 형태를 미리 보이고, 끝까지 계속 올리면 더 작아지며 홈으로 돌아간다. 광고 자료 대신 실제 iPhone 사용 캡처·화면 녹화의 버전을 확인하고 앱 UI를 비교한다. 잠금 화면 추가 장식과 앱 상세 기능 확장은 포함하지 않는다.

1. 실제 기기 참고 화면/모션 및 라이선스가 명확한 제스처 코드를 조사하고 원문·확인일·차이를 저장한다.
2. 속도 판정과 취소 회귀를 구현한다. 손을 뗀 위치에서 최종 상태로 이어지도록 홈/최근 앱/앱 재개 전환을 연결한다.
3. 실제 화면과 연락처·메시지·메모·사진 및 최근 앱의 레이아웃 차이를 수정한다.
4. 세 viewport, 두 엔진에서 자동 검사와 실제 프레임 캡처를 확인한다. 구현하지 않은 검토자가 코드·화면·기준 변경을 검토한다.
5. 현재 SHA 증거·필수 gate를 통과한 PR을 squash 병합하고 Pages 공개 동작을 확인한다.

코드 조사에서 `home`과 `switcher` 결과가 같은 callback으로 합쳐지고, release 시 offset을 먼저 지우며 시작 transform도 `none`으로 고정된 점을 발견했다. 성능 개선은 관찰한 프레임 비용과 전환 연속성으로 판단한다. 실기기를 실행하지 않은 경우 실제 Safari/ProMotion 검증으로 보고하지 않는다.
