# Issue 105: 메시지 복구와 승인된 화면 기준 정리

현재 main의 메시지 포인터 포커스 이동으로 재시도·다시 작성 버튼 터치가 유실되는 문제를 수정한다. Push presence 요청과 구독 요청을 구분하고 검사 시계의 경합을 제거한다. RAG 변경은 포함하지 않는다.

기존 상태표시줄·메시지 디자인 변경 이후 Linux 회귀 기준과의 차이는 별도 후보를 캡처하고 이전/이후 이미지를 직접 검토한다. 생성 자체를 승인으로 보지 않으며 의도한 차이만 독립 검토 후 채택한다. 허용오차·마스킹을 변경하지 않는다.
