# Issue #5 홈 화면과 #6 통합 검증 실행 계획

잠금 화면을 해제한 뒤 위젯·앱 격자·Dock과 페이지 이동을 제공한다. #6의 통합 검증은 같은 화면 연결을 검토하는 범위이므로 #5 PR에 함께 기록한다. 앱 내부·외부 API·스토리는 포함하지 않는다. 사용자 지시에 따라 잠금 화면 외형의 추가 정교화는 수행하지 않는다.

1. 격리 worktree의 홈 컴포넌트·데이터·제스처와 로컬 사진 자산을 통합한다.
2. 잠금과 홈의 포커스 이동, 페이지 변경·취소·짧은 화면의 스크롤 및 문자 확대를 확인한다.
3. 타입·lint·포맷·상태 로직과 Chromium/WebKit 동작 검사를 실행한다.
4. 잠금·홈 1/2페이지 × 세 크기를 고정 시간에 캡처한다. Apple 원본과 직접 비교하고 macOS/Linux 기준을 따로 검토한다.
5. 최종 diff·실제 캡처의 독립 리뷰와 현재 SHA의 필수 검사를 마친 뒤 squash 병합하고 Pages의 자산과 전체 흐름을 확인한다.

실제 결과는 별도 evidence와 PR에 기록한다. 실제 iPhone Safari는 사용 가능한 기기에서 실행한 관찰이 있을 때만 확인으로 기록한다.
