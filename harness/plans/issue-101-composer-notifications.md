# Issue 101

사용자의 입력창 여백 재발과 채팅방 내부의 사이트/OS 알림 억제를 함께 처리한다.

1. 기존 높이감지가 실패하는 geometry를 재현하고 입력폼 포커스에서도 footer 여백을 제거한다.
2. 채팅방의 사이트 배너는 폐기하되 읽지 않은 상태와 소리는 보존한다.
3. OS Push는 기존 인증 경로의 기기별 전경 lease와 실제 UI 도착 확인으로 발송 전에 억제한다. 이미 provider로 전송된 메시지를 회수하지 않는다.
4. lease만료/소유권/오래된순번/다른기기/화면전환을 로컬 검사하고 실제 캡처를 검토한다.
5. 사용자의 CI 생략 지시에 따라 로컬 검사·독립 리뷰 후 squash와 Pages build/deploy, 대기열이 비었을 때 API만 재시작한다.

실제 iPhone 키보드와 OS 배너 검증은 별도로 표시한다.
