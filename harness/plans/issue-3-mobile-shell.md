# Issue #3 — 모바일 공통 화면

## 목표와 범위

세 반응형 크기에서 viewport와 safe area를 다루는 공통 컨테이너, 작은 디자인 토큰, 한국어 날짜 표시 데이터를 만든다. 은색·샴페인 곡면의 직접 제작 배경을 사용한다. 잠금 시계·앱 grid·Dock과 제스처는 #4/#5의 범위다.

## 실행 순서

1. Apple 잠금·홈 이미지와 토큰 원문을 직접 확인한다.
2. 공통 컨테이너·토큰·날짜 데이터와 준비 화면을 분리한다. 배경은 프로젝트 SVG로 제작한다.
3. 날짜 경계, 세 크기, viewport 높이 변경, synthetic safe area, 문자 확대, reduced motion을 검사한다.
4. macOS 캡처와 Apple 원본을 비교하고 수정한다. Linux CI의 실제 캡처를 별도로 검토해 기준으로 등록한다.
5. 최종 diff·기준 이미지 변경을 독립 검토하고 현재 SHA의 증거로 PR을 병합한다.
6. Pages 배포 후 공개 화면과 자산을 확인하고 Issue에 기록한다.

## 판정 범위

기반 화면의 배경·화면 채움·가독성만 판정한다. Apple 화면 전체 일치나 실제 iPhone Safari 검증을 주장하지 않는다. 실행 결과는 별도 검증 기록과 PR에 남긴다.
