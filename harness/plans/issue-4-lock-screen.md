# Issue #4 — 잠금 화면과 해제

## 범위

첫 진입 잠금 화면, 한국 날짜·시계, 앞뒤 곡면 배경, 하단 제어 표현, 위로 밀기와 키보드 해제를 구현한다. 홈 도착 화면은 #5 통합 전까지 최소 상태다. 실제 Face ID·카메라·손전등 권한은 사용하지 않는다.

## 순서

1. Apple 원본을 직접 보고 시계·날짜·배경 겹침과 하단 제어 비율을 비교한다.
2. 독립 worktree에서 제스처 reducer/hook을 작성하고 주 작업 트리에 통합한다. 화면·공통 스타일·날짜 데이터는 조정 에이전트가 담당한다.
3. 세 크기와 두 엔진에서 실제 pointer 조작, 취소, 반복 입력, 키보드, reduced motion, 높이·문자 확대를 검사한다.
4. 실제 캡처를 원본과 비교해 수정하고 macOS/Linux 기준을 각 환경에서 검토한다.
5. 최종 diff·캡처 독립 리뷰, SHA 증거, PR squash 병합과 Pages 흐름 확인을 수행한다.

## 판정

시스템 글꼴과 자체 SVG를 사용한 웹 재현이다. Apple 배경·SF 폰트 원본을 복사하지 않는다. 실제 iPhone Safari 미검증은 자동 검사와 분리한다. 실행 결과는 검증 문서와 PR에 기록한다.
