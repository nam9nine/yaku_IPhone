# Issue #72 · 인물 프롬프트·원작 RAG·대화 기억

하루카·마지마의 일상 IF 입력을 원작 지식, 참고 장면, 실제 최근 대화, 과거 원문 기억으로 분리한다. 역할·말투뿐 아니라 상대와의 관계와 판단을 검증한다.

- 원작 1,201개 청크는 그대로 보존하고 별도 실행 registry에서 출처·범위·화자·train 분할을 검증한다.
- 인물·시나리오·방문자 범위를 먼저 제한한 BM25와 CPU multilingual-e5-small 검색을 수행한다.
- 관련 과거 교환에 후속 정정·취소를 연결한다. 원문과 시각은 보존하고 후보 연결을 확정 사실로 표시하지 않는다.
- system/실제 대화/final user envelope를 native 토큰 예산에 맞춰 조립한다. 핵심 system·현재 문자를 임의로 자르지 않는다.
- LongMemEval의 저장·검색·읽기 구분과 Mem0/Zep/Contextual Retrieval의 설계 선택을 검토하고 적용 범위·한계를 기록한다.
- 개발 질문과 독립 작성 후 고정한 holdout을 구분한다. 검색 성공을 답변의 정확도·팬 평가로 표시하지 않는다.

다중턴 실제 출력과 공개 UI 통합 검증은 #74에서 이어 수행한다. 각 평가 결과는 실행 후 별도 증거로 기록한다.
