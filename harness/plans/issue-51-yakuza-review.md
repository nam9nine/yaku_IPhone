# Issue 51: 주석 검토용 2차 전처리

## 목표

기존 정규화 자료에서 대사·메일·게임 진행 문맥·메타데이터를 구분하고, 원본과 다국어 문구를 함께 확인할 수 있는 로컬 검토 자료를 만든다. 모든 화자·청자·대화 순서는 미검증 상태로 유지한다.

## 관찰한 근거

- 전체 285,971행의 확장 정보는 원본 경로 `k`만 포함한다. 이름표와 발화 사이의 확정된 연결 정보가 없다.
- 후보 52,290행 중 50,588행에는 우선 인물 9명의 언급조차 없다. 인물 언급으로 필터링하면 대부분의 자료를 잃는다.
- 메일 `name` 필드는 본문과 구분해야 한다. 단순히 ‘눌러’·‘버튼’이 있다는 이유로 삭제하면 실제 대사를 잘못 제거한다.
- 같은 한국어·일본어 문장이 같은 장면과 다른 장면에 반복된다. 반복 그룹은 검토 정보로만 표시한다.

## 실행 순서

1. 정상 정규화 run의 설정·파일 경로·checksum과 행 수를 검증한다.
2. 원본 field/path에 근거한 파생 review lane을 정하고, 기존 정규화와 원문은 보존한다.
3. 출처·다국어 텍스트·미검증 라벨·보류 이유와 반복 그룹을 내보낸다.
4. 게임·분류 안에서 인물 언급·분류 사유·언어 경고별 결정론적 해시 표본을 만들고 원본 순서의 최초 표본과 구분한다.
5. 합성 fixture로 오류·경계 사례를 검증하고 전체 run을 두 번 처리한다.
6. 실제 집계·표본·보존 및 재현성을 독립 검토한다.

## 제한과 분리

장면 후보와 테이블 위치를 대화 순서로 확정하지 않는다. 화자·청자 또는 SFT 역할을 생성하지 않고 train/test 분할도 수행하지 않는다. 한국어가 없는 작품과 명단 밖 인물의 행도 원본 정규화 자료와 집계에 보존한다. 검토 문구는 ignored 로컬 경로에만 저장하고 Git에는 코드·합성 fixture·텍스트 없는 집계만 보관한다. UI와 모델 학습은 범위 밖이다.
