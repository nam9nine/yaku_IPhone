# Issue #73 — Mac 전용 대화 검토 화면

## 범위

SQLite 대화 원문을 읽는 Mac 소유자 검토 화면을 별도 loopback 포트에 만든다. 공개 메시지 UI·모델 실행·Cloudflare 설정은 변경하지 않는다. 검토가 학습 승인이나 캐릭터의 기억으로 자동 변환되지 않도록 한다.

## 구현 순서

1. 별도 소유자 서명 키·일회용 bootstrap·HttpOnly 세션과 Host/Origin·CSRF 경계를 구성한다.
2. 대화 필터/검색·우선순위·무작위 표본, 앞뒤 원문, 여섯 품질 축을 3열에 배치한다.
3. 원문·입력 근거·버전·측정값을 연결하고 메모·개선 답안을 별도 검토로 저장한다.
4. 최신 검토의 평가된 표본 수를 분모로 기간·버전별 현황을 제공한다.
5. 선택한 사례의 JSONL 내보내기에 비밀값 제외·학습 미승인 기본값을 적용한다.

## 검증과 제한

CPU 테스트로 무인증·다른 Origin·잘못된 Host·CSRF 누락·쿠키 위조·만료·로그아웃을 거절하는지 확인한다. 실제 Chromium·WebKit에서는 합성 DB로 평가 저장, 정정 사례 앞뒤 문맥, 실패 출력의 문자 표시, 현황과 내보내기를 조작하고 캡처를 직접 검토한다. 공개 증거에 실제 방문자 문자를 포함하지 않는다.

최종 diff·캡처의 독립 리뷰와 필수 gate를 통과한 뒤 병합한다. 관리자 UI 검사 성공을 실제 Gemma 품질이나 팬 검토 완료로 표현하지 않는다. 공개 연결 없이도 Mac 내부에서 검토할 수 있어야 한다.
