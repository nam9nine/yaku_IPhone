# 시각 회귀 기준 검토

화면 기준은 실제로 검토한 현재 동작을 기록한다. 승인된 UI·문구 변경 뒤 기준을 생략한 경우에도 이전 이미지와 현재 캡처를 직접 대조하고 원인을 기록한 후 갱신한다. 검사 실패만으로 현재 화면을 승인하지 않는다.

- 플랫폼·브라우저별 이미지는 해당 실행 환경에서만 생성한다.
- 현재와 이전 이미지를 같은 장면·viewport에서 비교한다.
- 폰 사건의 시계와 생성 결과는 고정 fixture를 사용한다. 실제 방문자 대화는 캡처하지 않는다.
- Issue #124는 볼링 사건 구현 전 main의 기존 화면과 기준 이미지 차이를 다룬다. 볼링 사건의 새 동작은 Issue #123에서 별도 검증한다.

구체 검토 기록과 실행 결과는 해당 Issue의 `harness/evidence/`에 보관한다. 최초 수집 단계는 검토 통과가 아니다.
