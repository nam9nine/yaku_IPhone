# 실사용 캡처 적용 — Issue 33

사용자가 대화에 첨부한 전화(최근 통화·연락처·키패드), 설정 목록, 메시지 목록·대화 화면을 직접 확인했다. 원본 첨부 파일의 로컬 경로는 제공되지 않았으므로 존재하지 않는 스크린샷 파일을 색인에 등록하지 않는다. 캡처의 실제 이름·번호는 복사하지 않는다.

- 전화: 검은 캔버스, 원형 상단 조작, 모두/부재중 필터, 아바타와 빨간 부재중 이름, 들여쓴 구분선, 다섯 항목의 하단 capsule, 큰 원형 키패드.
- 연락처: 중앙 제목, 위쪽 검색, 내 카드, 초성별 목록과 우측 색인. 홈에도 별도 앱을 배치한다.
- 설정: 큰 제목, 원형 프로필을 포함한 카드, 묶음별 행과 스위치. 프로필의 계정 표시는 창작 화면이며 Apple 계정 로그인은 하지 않는다.
- 메시지: 작은 중앙 제목, 하단 검색과 작성 버튼, 수신자 프로필, 회색 수신/초록 발신 버블. 기존 선택형 답장과 메모 링크를 유지한다.
- 최신 사용자 요청이 이전 상태바 미표시 결정을 대체한다. 웹 내 시간·Wi-Fi·통신 신호·배터리 행을 표시한다. 시간은 가상 16:40, 배터리는 80% 데모이며 기기 센서를 읽지 않는다.

수신 연출의 응답/거절 구조는 [Apple 수신 전화 안내](https://support.apple.com/guide/iphone/answer-or-decline-incoming-calls-iph3c9947bf/ios)를 함께 확인했다. 확인한 자동 선택 페이지는 iOS 26 자료로 표기되어 있으며 iOS 27 자료라고 단정하지 않는다. 앱 사용 중 배너, 잠금 중 전체 화면과 밀어서 받기, 키보드 응답 버튼을 제공한다. 15초의 무응답, 거절, 응답은 구분한다. 게임 음성·벨소리·실제 통화는 없다.

상단 시작 영역은 안전 영역 아래 40–112px의 좌우 구간으로 내린다. 버튼·입력·본문 스크롤에서 시작한 입력은 제외한다. 손가락 이동은 CSS transform으로 추적하며 짧은 입력·취소 후 원래 화면으로 복귀한다. 네이티브 iOS 가장자리 기능을 웹에서 차단했다고 주장하지 않는다.

갤러리는 `references/kiryu-gallery.json`의 실제 공식 게임 이미지 26장이다. `src/day/gamePhotos.json`에서 창작 설명과 순서를 바꿀 수 있다. 기존 창작 그림은 선택 배경으로만 남긴다. 기존 도시락·텃밭 선택 ID는 유효한 게임 사진으로 호환한다. ©SEGA이며 공식 공개 사실을 별도 재배포 허가로 표현하지 않는다.

이 문서는 요구사항과 구현 선택이며 테스트 통과 기록은 별도 증거에 남긴다. 실제 iPhone Safari 미검증.
