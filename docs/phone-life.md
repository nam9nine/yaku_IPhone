# 키류의 폰 문자·전화 흐름

Issue #107은 2026-10-29 첨부 요구를 기존 폰에 적용한다. 외곽 프레임·기존 사진 여섯 장·음악·카라오케·노트·초기화의 DB 보관 동작은 유지한다. 새 대사와 통화 대본은 원작 인물을 참고한 사이트용 IF 창작이며 공식 대사로 표시하지 않는다.

## 문자와 선택

- 마지마는 직접 입력과 짧은 선택 단계를 함께 제공한다. 성공한 문자 세 번마다 남은 선택 단계가 있으면 선택지를 제시한다. 실패한 전송은 이 횟수에 포함하지 않는다.
- 하루카는 완료한 할 일의 보고를 골라 보낸다. 답장은 기존 Gemma를 사용한다. 임의 자유 입력은 제공하지 않으며 과거에 보낸 자유 대화 기록은 보존한다.
- 다이고·사에지마·미네·다테·아키야마·유키는 각기 다른 주제의 세 번 왕복하는 선택형 문자다. 이 여섯 인물의 답장은 미리 작성한 IF 대본이다.
- 타이핑 말풍선은 표시하지 않는다. AI 답장의 기존 무작위 읽음·도착 지연은 유지한다. 로컬 선택형 답장은 사이트가 보이는 동안 6–12초 후 도착한다.
- 연락처 하나에 답장을 기다리는 동안 다른 연락처에 바로 보낼 수 있다. 서버는 방문자·인물·시나리오당 활성 요청 하나, 방문자당 둘, 전체 FIFO 여덟 개를 허용한다. 추론 모델은 한 슬롯에서 순서대로 생성한다.
- 선택형 AI 문자는 실제 성공한 같은 request ID의 답장 이후에만 선택 완료·인연에 반영한다. 실패하거나 잘린 답장은 선택 완료로 계산하지 않는다.

## 인연·전화·할 일

마지마 선택과 통화 반응은 로컬 인연 값 -5…5에 반영된다. -2 이하·2 이상에서 각각 서늘함·친근함의 임시 대화 조건을 사용한다. 마지마 통화를 12초 이상 이어가고 종료하면 +1, 거절·짧은 종료는 -1이며 놓친 전화는 값이 바뀌지 않는다. 이는 구현 기본값이고 원작 관계나 과거 사건을 바꾸는 설정이 아니다. 사용자가 선택할 수 있는 모델 입력은 검증된 세 가지 상태뿐이며 임의 시스템 문장은 받지 않는다.

전화는 인물별 텍스트 대본으로 진행하며 발신·수신·종료·최근 통화를 기록한다. 새 자동 전화는 잠금 해제 상태에서 사이트를 보는 사용 시간으로 예약하고, 숨긴 동안 진행시키지 않는다. 첫 전화는 60초 후, 이후는 180–360초 간격이 기본이다. 장보기 완료 전화는 별도 한 번 유지한다. 마지마의 거절·이른 종료에는 후속 문자와 다음 전화가 이어진다. 실제 사람과 통화하거나 AI 음성을 생성하는 기능은 아니다.

마지마 수신음은 기존 24시간 신데렐라 0–32초 파일이다. 다른 인물은 기존 알림 녹음 파일을 반복 재생한다. 배우의 추가 한마디 음성은 원본 확보 전까지 재생하지 않는다.

할 일은 기존 장보기·텃밭·마메에 체육복 이름표·택배를 추가했다. 완료 이벤트는 중복되지 않으며 관련 인물의 문자로 이어진다. 요리 앱 이름은 나팔꽃키친, 택시는 류큐 거리·카무로쵸의 가상 목적지를 선택한다. 니시키는 전화 연락처에서 제외하고 기존 저장된 다른 진행 상태는 유지한다. 원작 RAG에서 니시키라는 인물을 삭제한 것은 아니다.

## 저장·알림·제한

로컬 전화·선택·인연은 기존 day 저장소에서 이전 형식을 이관한다. AI DB v2는 이전 기록·토큰·UUID를 보존하면서 연락처별 활성 요청 제약으로 이관한다. API와 관리자 동시 시작도 SQLite 쓰기 잠금 안에서 버전을 다시 확인한다.

AI 답장 여러 개가 함께 도착해도 각각 수신 확인하고, 새 도착 소리만 한 번씩 재생한다. 로컬 이야기 문자도 도착 시 앱 안 알림·읽지 않음을 표시한다. 채팅방에 있는 동안 상단 배너는 나타나지 않는다. 초기 기록을 읽거나 앱을 열었다는 이유로 소리를 재생하지 않는다. 로컬 대본은 Mac 서버가 생성하지 않으므로 사이트가 닫혔을 때 OS push를 보내지 않는다.

비노골적 대화 원칙은 모델 공통 지침과 명확한 성적 역할극 요청·출력에 대한 좁은 검사로 적용한다. 원작의 싸움, 일반적인 애정 표현, 피해 상담을 일괄 차단하지 않는다. 규칙 검사는 의미 기반 완전 분류기가 아니며 새 표현에 대한 팬·운영자 검토는 계속 필요하다. 차단된 생성은 실패 기록으로 남고 정상 대화 기억에는 들어가지 않는다.

지정 꽃 아이콘·추가 사진·실제 목소리 원본은 미확보 상태다. 확인 전에는 대체 생성물을 요청한 원본으로 표시하지 않는다. 친구 한정 공개의 구체적인 접근 정책도 사용자 선택 전까지 기존 무설정 공개 접속을 유지한다. GitHub Pages의 정적 앱 자체를 비공개로 만드는 기능은 이 변경에 포함하지 않는다.
