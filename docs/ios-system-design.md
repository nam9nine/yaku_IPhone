# iOS 시스템 화면의 디자인 근거

[Issue #20](https://github.com/nam9nine/yaku_IPhone/issues/20)은 시스템 패널의 독자적인 제목·닫기 X·설명·하단 보조 바를 없애고 Apple 공식 화면의 구성과 재질에 맞추는 작업이다. 대상은 제어 센터, 최근 앱, 알림 센터, 홈 인디케이터다. 다음은 2026-10-24에 원문과 이미지를 직접 열어 기록한 관찰과 구현 기준이며 앱 구현의 통과 결과가 아니다.

## 원본과 버전

URL·SHA-256·바이트 수·원문 경로·이용 범위는 [manifest](../references/manifest.json)가 원본이다. 기존 제어 센터·최근 앱 ID를 재사용한다.

| Reference ID                                                                      | 근거와 사용 범위                                                                                              |
| --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `apple-control-center`, `apple-control-center-image`                              | iOS 27 User Guide의 제어 센터 동작과 전체 이미지                                                              |
| `apple-app-switcher`, `apple-app-switcher-image`                                  | iOS 27 앱 전환 동작과 겹친 카드 이미지                                                                        |
| `apple-app-switcher-drag-gesture-image`, `apple-home-swipe-gesture`               | 아래끝 상승·멈춤 도해와 홈/앱 전환 설명                                                                       |
| `apple-quit-app`                                                                  | 최근 앱 카드 위 스와이프에 의한 종료                                                                          |
| `apple-notification-center`                                                       | iOS 27 알림 센터 동작. 전체 화면 이미지는 없음                                                                |
| `apple-notifications-support`                                                     | Apple Support 108781의 설명과 이미지 출처                                                                     |
| `apple-notifications-ios26-lock-image`, `apple-notifications-ios26-options-image` | **iOS 26 / iPhone 16 Pro 보조 이미지**. 현재 문서에 있지만 파일명이 iOS 26이며 iOS 27 확정 화면으로 쓰지 않음 |
| `apple-lock-screen-image`, `apple-home-indicator-visibility`                      | 실제 흰 막대 모양과 UIKit의 표시 정책                                                                         |
| `apple-copyright`                                                                 | Apple 저작권 표시. 로컬 참고용이며 MIT가 아님                                                                 |

문서의 iOS 27 버전 지정과 이미지의 모든 상태가 iPhone 18 Pro의 단일 기본 설정이라는 주장은 구분한다. 제어 센터는 편집 가능하며 색조는 벽지와 glass에도 영향을 받는다. 한 픽셀의 색을 모든 상태의 고정 색으로 단정하지 않는다.

## 비교 영역과 수치

아래는 **PNG에서 관찰한 근사값이며 Apple의 pt 규격·CSS viewport·제스처 임계값이 아니다.** 실제 viewport와 safe area에 적용한 뒤 캡처로 확인한다.

| 항목               | 원본 관찰                                                  | 구현 시 의미                                                     |
| ------------------ | ---------------------------------------------------------- | ---------------------------------------------------------------- |
| 제어 센터 PNG      | 782×1008px. 기기는 왼쪽 약490px, 나머지는 문서 콜아웃 공간 | PNG 전체 폭을 화면 폭으로 쓰지 않음                              |
| 제어 센터 내부     | 대략 x22–467, y20–986, 445×966px                           | 외곽 프레임·Dynamic Island·지시선을 제외한 비율 비교             |
| 연결/미디어 타일   | 각172×172px, 내부 폭의 약38.7%                             | 두 정사각 그룹을 같은 행에 배치                                  |
| 원형 제어 / 간격   | 지름약78px / 간격약17px, 내부 폭의 약17.5% / 3.8%          | 네 열의 원형 도구와 일정한 간격                                  |
| 밝기·음량 / Focus  | 약78×172px / 172×78px                                      | 세로 조절기와 가로 capsule                                       |
| 주 제어 영역       | x63–424, y165부터 시작                                     | 내부 폭의 약81%, 위에서 약15%에 첫 그룹                          |
| 최근 앱 PNG / 카드 | 490×1008px / y160–826 약666px                              | 내부 화면 높이의 약69%인 긴 카드. 가려진 전체 폭은 단정하지 않음 |
| 앱 표식            | 카드 위 약30px 아이콘과 작은 흰 앱 이름                    | 카드 콘텐츠 밖의 앱 표식                                         |

프레임·가짜 상태바·Dynamic Island는 만들지 않는다. 제어 센터의 `+`/전원과 연결·배터리 줄은 외곽 상태바와 구분한다. 문서의 오른쪽 콜아웃 선은 UI가 아니다.

## 화면별 관찰과 변경 이유

### 제어 센터

작은 `+`와 전원, 연결·배터리 정보 아래에 연결/미디어 그룹이 있다. 연결 그룹은 큰 원형 제어와 작은 하위 제어 묶음이다. 미디어 그룹에는 작은 그림 영역·AirPlay·재생 상태·이전/재생/다음 아이콘이 있다. 다음 영역은 회전 잠금·벨, Focus, 밝기·음량 세로 capsule이다. 아래에 손전등·타이머·계산기·카메라, 화면 미러링·코드 스캔 원형 제어가 놓인다. 오른쪽 그룹 레일은 하트·음악·연결을 세로로 표시한다.

배경은 홈 화면을 강하게 흐린 모습이다. 컨트롤은 반투명 유리, 밝은 가장자리, 색조와 흰 glyph를 가진다. 기존 글자형 연결 카드·켬/끔 설명·가로 밝기 range·다크 모드 단독 카드·가로 페이지 점·설명 페이지는 이 기준과 다르다. 지원 조작은 공유 상태와 연결하되 모양을 그렸다는 이유로 실기기 제어가 작동한다고 기록하지 않는다.

### 최근 앱

홈·Dock이 흐려지고 긴 실제 앱 화면 카드가 가로로 겹친다. 가장자리 카드가 화면 밖으로 잘리며 분리된 작은 썸네일 목록이 아니다. 아이콘과 이름은 카드 밖 위에 있다. 큰 제목, 카드별 X, 사용 중 배지, 설명문, 하단 페이지 버튼은 보이지 않는다. 원본 Notes·Photos 카드 안의 도구 모음은 해당 앱 콘텐츠이며 전환기의 공통 푸터가 아니다.

실제 앱 상태를 이용한 미리보기, 카드 선택의 세션 재개, 가로 탐색과 카드 위로 닫기를 유지한다. 배경·막대 상승·Escape로 전환기를 닫으면 홈으로 간다. 이 dismiss 정책은 이 체험의 탐색 동작으로 구현하며 정적인 이미지에서 동작을 확인했다고 기록하지 않는다.

### 알림 센터

iOS 27 문서는 좌상단에서 내려 열기, 아래끝에서 올려 닫기와 알림 관리 동작을 확인시켜 준다. 전체 이미지가 없어 iOS 26 보조 자료의 날짜·시계·벽지와 아래쪽 유리 알림 배치를 참고하되 버전 한계를 적는다. 보조 이미지에는 하단 손전등·카메라와 흰 막대가 보인다.

지원 범위에는 수신 알림·계정 연결이 없다. 큰 벨·빈 상태 카드·웹 설명문·시계와 빈 상태를 나누는 가로 페이지를 공식 형태로 간주하지 않는다. 알림 지우기 X와 패널 닫기 X는 다른 기능이다. 임의 알림이나 확인하지 않은 큰 제목을 추가하지 않는다.

### 홈 인디케이터

공식 잠금 이미지에는 흰 막대가 보이지만 제어 센터·최근 앱 이미지에는 보이지 않는다. UIKit은 자동 숨김 정책을 제공하므로 모든 화면에 항상 흰 막대가 있다고 주장하지 않는다.

사용자 요구로 홈·앱·시스템 패널에 visible 막대를 추가한다. 기본 흰색, 밝은 앱에서는 대비를 위한 검정색이다. 홈·앱에서 일정 거리 올리면 pause 없이 최근 앱을 열고 미완료 드래그는 원위치로 복구한다. 실제 iOS의 올리기→멈춤→손 떼기와 다른 선택이다. 색·보임·제스처 차이는 시각 증거에 명시한다.

## 재현과 검증의 경계

Apple 스크린샷·벽지·추출 아이콘을 앱으로 붙이지 않는다. 현재 React와 CSS 도형·재질로 구조를 재현한다. 대체 조작은 sr-only 또는 포커스 시 표시해 접근성 이름·포커스 관리·Escape를 유지하고 상시 보조 바를 만들지 않는다. 세로 스크롤 금지는 유지하며 작은 높이·큰 글자에서 가로 탐색으로 지원 조작에 도달하는지 확인한다.

실제 Wi-Fi·Bluetooth·전원·기기 밝기·시스템 음량·알림 권한·설치 앱을 제어하지 않는다. CSS blur와 iOS 합성 재질은 다를 수 있다. 실제 iPhone Safari의 safe area·브라우저 크롬·OS 제스처 우선권을 desktop WebKit으로 확인했다고 기록하지 않는다. [시각 QA](visual-qa.md)와 [Issue #20 계획](../harness/plans/issue-20-ios-system.md)에 따라 실제 결과를 남긴다.
