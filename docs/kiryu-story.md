# 키류의 폰: 스토리와 화면 근거

확인일: 2026-10-24 (Asia/Seoul). 출처·원본 URL·버전·해시는 [스토리 자료 색인](../references/story-sources.json)에 기록한다. 원문과 Apple 화면은 `references/local/story/`, 실제 표시하는 SEGA 이미지 원본은 `public/story/`에 보관한다.

## 설정의 경계

이 프로젝트는 키류 카즈마의 휴대전화를 상상한 팬 창작이다. 사에지마·다이고·미네·마지마·하루카가 모두 연락 가능한 상황은 사용자 요청에 따른 별도 설정이며, 특정 작품의 연도나 사건 직후라고 단정하지 않는다. 인물 사진은 서로 다른 작품의 공식 홍보 자료를 사용한다.

메시지, 답장, 요리 계획, 장보기 수량, 사진 제목·날짜와 휴대전화 사용 메모는 프로젝트가 새로 작성하는 창작 내용이다. 게임에 실제 등장한 대사나 키류의 공식 기록이라고 표시하지 않는다. 특히 “키류가 스마트폰을 잘 다루지 못한다”는 사용자 콘셉트이며 아래 공식 소개에서 확인한 정사 사실과 구분한다. 대사는 복사하지 않고 짧고 담백한 일상 대화로 작성한다.

사에지마 타이가는 전 동성회 직계 사에지마조 조장이며 마지마의 의형제로 소개된다. [SEGA Pirate 공식 인물 소개](https://ryu-ga-gotoku.com/pirate/cast/)의 인물 사진을 사용한다. 본 프로젝트의 문자에는 인물의 결말이나 해당 작품 사건을 끌어오지 않는다.

나팔꽃의 아이들은 타이치·코지·시로·미츠오·아야코·리오나·에리·이즈미다. 공식 일상 소개에는 요리, 채소 재배, 숙제, 재봉질, 낚시가 포함된다. [SEGA 나팔꽃에서의 일상](https://ryu-ga-gotoku.com/kiwami3/kr/kiwami3-adventure/kiwami3-adventure-life/)

## 창작 메모의 내용 기준

- **아이들 저녁 준비:** 카레나 햄버그 등 한 끼 요리 계획. 밥을 먼저 안치고, 아이들과 하루카의 몫도 충분히 준비하는 식의 간단한 순서를 담는다. 메뉴와 취향을 공식 설정으로 주장하지 않는다.
- **장보기:** 쌀, 감자, 당근, 양파, 고기, 달걀, 우유와 같은 실제로 체크할 수 있는 짧은 목록. 냉장고 확인과 중복 구매 방지를 적는다.
- **전화 쓰는 법:** 연락처에서 이름 누르기 → 메시지 → 글을 적고 화살표 누르기. 홈으로 나가기, 왼쪽 끝에서 뒤로 가기, 사진 열기 같은 이 앱의 실제 동작만 설명한다. 서투르지만 성실하게 적은 말투를 사용한다.

## 자산 확인과 권리

6명의 인물 원본과 4장의 일상/거리 사진을 직접 열어 확인했다. `sewing.jpg`는 재봉틀 앞의 키류와 아이이므로 요리 사진으로 표시하지 않는다. `family-time.jpg`는 함께 식사하는 나팔꽃 가족, `morning-glory.jpg`는 아이들 단체, `okinawa.jpg`는 류큐 거리다. 사에지마는 투명 배경 전신 PNG이므로 원형 프로필에서는 위쪽 얼굴이 보이게 표시한다.

이미지는 원본 바이트를 보존했다. 사진 표시를 위한 CSS 크롭 외에 생성·합성·인물 변경을 하지 않았다. 자산의 권리자는 SEGA이며 공개 웹사이트에서 가져왔다는 이유로 자유 이용 허가나 오픈소스 라이선스를 주장하지 않는다. 프로젝트 코드의 라이선스가 이 이미지에 적용되지 않는다. Apple 원본 화면은 로컬 비교 자료이며 앱 번들에 포함하지 않는다.
