# 개인 사진과 암호·벨소리

Issue #54의 사용자 확정값인 암호 `1225`, 사진 여섯 장, 마지마 수신 화면의 시간 아래 `마지마형님`은 유지한다. Issue #107의 최신 요청은 이전의 '힌트 없음' 결정을 대체한다. 암호 화면에는 `크리스마스는 몇 월 며칠이지.`라는 짧은 힌트를 표시하며, 특정 원작 사건이나 인물의 실제 메모라고 주장하지 않는다. 암호는 이 웹 경험의 잠금 연출이며 서버 인증이나 자료 접근 통제가 아니다.

## 잠금과 목적지

잠금 화면의 위로 밀기와 해제 버튼은 숫자판을 연다. 메시지 알림·캘린더·미리 알림은 목적지를 보관한 뒤 같은 숫자판을 거친다. 취소와 오답은 잠금을 유지하고, 맞는 네 자리가 입력된 경우 한 번만 해제한다. 다시 잠그거나 새로고침하면 다시 입력한다. 키보드 숫자·Backspace·Escape·Tab 대체 조작과 동작 줄이기를 지원한다.

일반 화면과 알림 센터는 암호 모달 아래에서 입력을 받지 않는다. 잠금 시계와 알림이 숫자판과 겹치지 않도록 입력 중에는 배경과 상태바만 보인다. [Apple의 암호 안내](https://support.apple.com/en-us/119586)는 잠금 해제 단계와 네 자리 옵션의 동작 참고이며, 이 앱의 암호를 실제 보안 기능으로 주장하지 않는다.

## 사진

`src/day/personalPhotos.json`은 사용자가 보낸 여섯 장과 개인 메모를 관리한다. `references/personal-media.json`은 첨부 순서·원본 SHA·크기·출처 상태를 기록한다. 사진 원본을 재생성하거나 저작권 표기를 지우지 않았다.

갤러리에는 새 여섯 장만 표시한다. 이전 `gamePhotos.json`과 자산은 기존에 선택한 배경과 즐겨찾기 ID 호환을 위해 보존한다. 기본·그림·바다 배경은 그대로이며 새 사진도 배경으로 사용할 수 있다. 홈 위젯은 가족 사진을, 장보기 완료 후에는 마메 사진을 연다.

## 수신 벨소리

`public/audio/majima-ringtone.m4a`는 사용자가 지정한 공개 영상의 0–32초 구간이다. 출처·범위·파일 검증값과 허가 미확인 상태는 `references/ringtone-source.json`에 남긴다. 제품 화면에는 출처 패널을 추가하지 않는다.

한 미디어 요소를 사용하며 첫 사용자 입력에서 무음 준비를 시도한다. 수신 중에만 소리를 내고 응답·거절·만료·초기화·컴포넌트 제거·문서 숨김 때 정지한다. 제어 센터의 무음과 음량 0도 정지하며, 음량을 복원하면 유효한 수신 중에만 다시 재생한다. 자동 재생 거부는 잡아서 처리하고 다음 사용자 입력에서 재시도한다. 재생 Promise가 늦게 끝나도 종료된 통화를 다시 울리지 않는다.

기존 무응답 만료는 15초이므로 파일 끝까지 항상 재생되는 것은 아니다. 반복 수신과 통화 중 텍스트 대사는 별도 후속 작업이다. 실제 iPhone Safari에서의 미디어 재생 확인은 데스크톱 WebKit 결과와 구분한다.
