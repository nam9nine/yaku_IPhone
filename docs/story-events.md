# 부탁에서 행동으로 이어지는 폰 이벤트

2026-10-29 사용자의 “스토리를 보고, 하루카 문자처럼” 요청을 반영했다. 아래 문자는 사이트용 IF 창작이다. 원작의 사건을 그대로 재연했다고 표시하지 않으며 연대순 제약은 적용하지 않는다.

## 확인한 원작 근거

- [SEGA 극 3 공식 매뉴얼](https://manual.sega.jp/ryu-kiwami3/en/): 하루카는 키류와 아이들의 생활에 적극적으로 관여하고, 집안일·요리·아이들과의 교류가 관계를 만드는 활동이다. 따라서 하루카는 수동적인 칭찬만 반복하지 않고 일을 나누고 확인하는 역할을 맡는다.
- [SEGA 극 공식 매뉴얼](https://manual.sega.jp/switch/ryu-kiwami/en/index.html): 마지마는 도시의 여러 장소에서 키류에게 도전하며 겨루는 관계다. 이번 만남 제안도 그 동기를 따른다. 부상이나 실제 급한 사정에도 무조건 싸움을 강요하는 규칙은 만들지 않는다.
- [SEGA ONLINE 다테 소개](https://ryu.sega-online.jp/special/character/ce43b1ea/): 다테는 키류와 여러 사건을 함께한 형사다. 연락의 기반을 생활 공동체가 아닌 오랜 신뢰와 부탁으로 구분한다. 물건을 맡아둔 봉투 사건 자체는 이번 IF 창작이며 원작 사건이라는 근거는 없다.

텃밭·마메는 작은 생활 부탁으로 유지한다. 서로 다른 인물에게 같은 아이들 안부를 반복 배정하지 않는다. 유키는 가게, 미네는 다이고에게 전할 일정, 사에지마는 산책, 아키야마는 자신의 일 이야기로 구분한다.

## 상태와 문맥 규칙

- 미리 알림 체크·전화·목적지 알리기는 브라우저 IF 사건이다. 실제 구매·이동·싸움의 완료를 검증한 것으로 바꾸지 않는다.
- 자동 후속 문자는 퀘스트마다 한 번이다. 체크를 풀었다 다시 체크해도 문자·전화가 중복 발생하지 않는다. 카무로쵸 연락도 명시 버튼을 한 번 누를 때만 발생한다.
- 다른 통화 중에는 목적지 알리기를 비활성화하고 이유를 표시한다. 초기화하면 이벤트 진행과 인연을 새로 시작한다. 새로고침은 완료된 이벤트를 재발송하지 않는다.
- AI는 서버가 검증한 이벤트 ID의 고정 설명을 최근 네 개까지 받는다. 다른 인물의 사건, 임의 클라이언트 문장, 원작 사실로 위장한 사건은 받지 않는다. 최신 대화의 정정이 우선이다.
- 최근 사건은 제한된 문맥이다. 오래된 모든 통화 대본을 AI가 그대로 기억한다고 보장하지 않는다. 실제 AI 문자 이력은 별도의 DB·기억 검색 경로로 유지한다.
- 반복 전화는 활성 사용 시간으로 예약하며 화면을 닫은 동안 쌓아두지 않는다. 통화 중 캐릭터 음성은 폐기했고 텍스트와 수신 벨소리만 사용한다.

## 검토 기준

부탁이 먼저 있고 행동 뒤에 맞는 인물이 반응하는지, 목적지 선택을 도착으로 오해하지 않는지, 다른 사건의 대사가 섞이지 않는지, 거절·완료·재접속·초기화에서 중복이 없는지 검사한다. 고정 대사에 대한 원작 팬의 말투 평가는 아직 별도다.

## 마지마의 선제 연락

활성 사용 중 첫 전화는 60초, 다음 전화들은 120–240초 간격이고 마지마와 다른 인물을 번갈아 배치한다. 선제 문자는 처음 90초, 다음부터 90–180초 간격이다. 통화·AI 답장 대기·로컬 선택 답장 대기에는 겹치지 않으며 통화 뒤 최소 60초, 문자 뒤 전화는 최소 45초를 둔다. 숨김·잠금 시간을 적립해 재접속 순간 한꺼번에 보내지 않는다.

선제 문자 여덟 개는 검토 가능한 IF 대본이다. 폰 확인, 겨루기 제안, 노래 제안, 전화 요청 등으로 주제를 나누고 각 문자는 초기화 전 한 번만 보낸다. 원작 인용이나 모델 생성 답장으로 표시하지 않는다. 인연이 서먹할 때는 친근한 선제 문자를 보류한다. 보내진 문자는 기존 알림·읽지 않음·채팅 이력에 연결되고, 해당 이벤트 ID의 실제 문구가 이후 마지마 AI 요청에 들어가서 사용자의 답장 대상을 알 수 있게 한다. 사용자가 수락했다거나 실제 이동·대결을 마쳤다고 만들지 않는다. 대본을 다 보낸 후에도 전화는 이어진다.
