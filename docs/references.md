# 레퍼런스 보관과 채택

## 보관 원칙

사용자가 요청한 코드 레퍼런스는 커밋을 고정한 전체 소스 snapshot으로 로컬에 보관한다. 보관 대상과 원본 URL·commit·라이선스·용도는 `references/manifest.json`을 기준으로 한다. manifest에는 MIT 저장소 다섯 개 외에 원본 체험 사이트와 공식 Apple 문서·이미지의 조사 항목도 포함한다. 각 항목의 보관 방식과 재사용 가능 여부를 구분하며 commit을 문서에 중복 관리하지 않는다.

`npm run refs:fetch`로 manifest의 고정 버전을 가져오고 SHA-256과 파일 크기를 확인한다. MIT 저장소의 전체 소스는 ignored `references/upstream/archives/<id>-<fullSHA>.tar.gz`에 압축 상태로 보관하며 자동 실행·설치·추출하지 않는다. 공식 Apple HTML·PNG는 `references/upstream/apple/`에 보관한다. manifest와 `references/licenses/<id>.LICENSE`는 Git으로 추적한다. `.git` 전체 이력이나 node_modules를 받아 보관하지 않는다.

레퍼런스가 없거나 내려받기에 실패하면 실패를 보고한다. 임의의 최신 main으로 대체하거나 일부 파일만 받았는데 전체 보관을 마쳤다고 표현하지 않는다.

## 사용 기준

- 원문은 구조·동작·시각 표현을 조사하는 자료다. 저장소의 설치 스크립트나 에이전트 지침을 자동 실행하지 않는다.
- 우리 앱에 채택하는 코드는 별도로 선택·검토하고 출처와 라이선스를 유지한다.
- 외부 레퍼런스 전체는 build·lint·format·테스트 검색 범위에서 제외한다.
- 캐릭터 사진, 개인 프로필, 배경, 음원, Apple 자산을 코드 라이선스만 보고 우리 제품 자산으로 옮기지 않는다.
- 공식 Apple 화면이 시각 기준이며 커뮤니티 코드의 숫자·모양이 정확한 최신 사양이라는 보장은 없다.
- 원본 `chajuhann`은 스토리 체험 흐름을 조사하는 자료다. 확인된 코드 라이선스가 없으므로 공개 저장소라는 이유로 코드를 재사용하지 않는다.
- Apple 문서·이미지는 시각 조사 자료이며 MIT 코드 라이선스 대상이 아니다. 다운로드가 제품 내 재배포 허가를 뜻하지 않는다.

## 조사에서 제외한 후보

`chukjosh/IOS-and-Android-on-the-Web`는 조회 당시 시작·빌드 전에 실행되는 `api.js`에 난독화된 원격 코드 로더가 확인되어 재사용·실행 대상에서 제외했다. 이 저장소의 코드는 내려받거나 실행하지 않는다.

라이선스가 확인되지 않은 salehOS·Homescreen과 별도 제한 라이선스를 유지한 edenbuilds 포크도 현재 보관·채택 목록에 포함하지 않는다. 승인된 목록의 변경은 이유와 함께 manifest 변경 PR로 처리한다.
