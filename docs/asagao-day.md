# 키류의 iPhone — 나팔꽃의 평범한 하루

Issue #30의 콘텐츠와 상태 계약이다. 최신 사용자 지시에 따라 기존 iOS 스타일을 유지하며 iOS 18로 다시 디자인하지 않는다. Apple 공식 사용 설명서의 실제 화면을 구조·비율 비교에 사용한다. 웹에서 가능한 모사이며 실제 iOS 전체나 동일한 기기 글꼴·렌더링을 보장하지 않는다.

## 일상과 흐름

하루카가 휴대폰 정리를 도왔고 키류는 아이들을 챙기는 메모와 사진을 남겼다는 창작 설정이다. 나팔꽃에서 보내는 평온한 토요일을 현대 스마트폰으로 재해석한다. 원작 연도에 고정하지 않으며 후속 작품의 결말은 다루지 않는다.

잠금 알림은 하루카 대화, 대화 속 목록은 `curry` 메모, 일정 위젯은 캘린더, 할 일 위젯은 미리 알림, 날씨 위젯은 나팔꽃의 날씨 상세를 연다. 홈 사진 위젯은 표시 중인 사진을 연다. Dock에는 전화·메시지·Safari·메모, 홈에는 사진·캘린더·미리 알림·설정을 둔다. 작은 화면에서 필요한 만큼 가로 페이지를 만든다.

감자·양파·고기·카레가 모두 체크되면 ‘저녁 장보기’가 완료된다. 당근은 이미 있는 재료이므로 진행 수에 포함하지 않는다. 미리 알림에서 장보기를 직접 완료하면 같은 네 재료를 함께 갱신한다. 텃밭과 마메 항목은 별도로 체크한다. 잠금 위젯은 이 데이터에서 남은 수를 계산한다.

장보기 완료 뒤 ‘다 샀다.’를 선택하면 하루카의 답장이 함께 저장된다. 최초 장보기 완료는 마지마의 전화 수신을 한 번 시작한다. 응답하면 무음 통화 시뮬레이션으로, 거절하거나 15초 동안 응답하지 않으면 부재중 알림과 통화 기록으로 이어진다. 수신 중 새로고침하면 부재중으로 복원한다. 재료를 다시 해제하거나 앱을 재진입·새로고침해도 메시지와 전화 이벤트는 중복 발생하지 않는다. 시간에 따라 자동으로 스토리를 진행하지 않는다.

## 데이터와 저장

- `src/day/content.ts`: 가상 시각, 메모, 미리 알림, 일정, 선택형 대화.
- `src/day/state.ts` / `DayContext.tsx`: 재료·할 일·읽음·답장·수신/응답/부재중 전화의 공유 상태. `yaku-iphone.day.v1`.
- `src/day/media.ts`: 사진 경로·제목·설명·초점과 배경 선택.
- `DevicePreferences`: 화면 모드·가상 연결·밝기·글자 크기·배경·사진별 위치. `yaku-iphone.preferences.v1`.
- 일반 메모와 사진 즐겨찾기는 프로젝트 전용 story 저장 키를 사용한다.

저장값 구조를 검증하고 잘못된 값은 기본값으로 복구한다. 읽기·쓰기 실패는 예외를 화면 밖으로 전파하지 않으며 현재 세션의 상태를 유지한다. 초기화는 확인 대화상자 후 프로젝트 키와 메모리 상태만 초기화한다. 다른 사이트 데이터는 지우지 않는다. 앱 내부 탐색과 Safari 탭은 세션 상태이며 전체 새로고침 시 잠금 화면으로 돌아온다.

## 웹 체험의 범위

가상 날짜는 2026년 10월 24일 토요일 16:40으로 고정한다. 날씨 27°와 ‘라라라 모바일’, Wi-Fi `ASAGAO_HOME`은 데모 설정이다. Issue #37의 사용자 요청으로 가상 데이터·팬 창작·출처 설명은 제품 화면에 표시하지 않고 이 문서와 references/에서 관리한다. Safari의 요리·바느질·도시락 검색 결과는 저장된 가상 페이지이며 외부 주소는 안내 후 명시적으로 외부 브라우저를 열 때만 이동한다.

PC 프레임은 390×844를 최대 내부 크기로 사용하며 화면 높이에 맞춰 줄인다. 모바일에는 바깥 프레임을 추가하지 않는다. 앱·시스템 패널·홈 막대는 같은 화면 경계를 공유한다. 화면과 앱 내용을 분리해 문서 전체의 스크롤을 막고 생활 앱 내용은 스크롤할 수 있게 한다.

실제 통화·SMS·생체 인증·잠금 변경·권한 요청·자동 음성은 없다. Playwright의 데스크톱 WebKit 검사는 실제 iPhone Safari, 실제 키보드나 기기 성능 확인을 대신하지 않는다.
